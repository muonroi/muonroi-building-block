═══════════════════════════════════════════════════════════════════════
                            DATA FLOW
═══════════════════════════════════════════════════════════════════════

1. APPLICATION STARTUP
   ─────────────────────
   │
   ├─ Load license.json
   ├─ Verify license tier (Free/Licensed/Enterprise)
   ├─ Load policy.json (if exists)
   │  └─ Verify RSA signature
   ├─ Start background services
   │  └─ ChainSubmissionHostedService (if Tier 3 enabled)
   └─ Ready to serve requests


2. HTTP REQUEST PROCESSING
   ────────────────────────
   Client → HTTP Request
      │
      ├─ LicenseMiddleware intercepts
      │  │
      │  ├─ TIER 1: Check license tier
      │  │  └─ Free: Allow all
      │  │  └─ Licensed/Enterprise: Check features
      │  │
      │  ├─ TIER 2: Check policy (if exists)
      │  │  └─ PolicyEnforcer.CheckApiRateLimit()
      │  │     └─ counter.Increment() > limit?
      │  │        ├─ NO:  Continue
      │  │        └─ YES: Throw exception (HTTP 500)
      │  │
      │  └─ TIER 1: Record action
      │     └─ Save to chain log (async)
      │
      └─ Continue to controller


3. DATABASE OPERATION
   ───────────────────
   DbContext.SaveChanges()
      │
      ├─ LicenseSaveChangesInterceptor intercepts
      │  │
      │  ├─ Check LicenseExecutionContext.IsInLicenseCheck
      │  │  └─ TRUE: Skip (prevent loop)
      │  │  └─ FALSE: Continue
      │  │
      │  ├─ TIER 1: using (BeginScope())
      │  │  └─ guard.EnsureValid("db.savechanges")
      │  │
      │  ├─ TIER 2: PolicyEnforcer.CheckDbRateLimit()
      │  │  └─ counter > limit? → Throw exception
      │  │
      │  └─ Continue save
      │
      └─ Database updated


4. CHAIN SUBMISSION (TIER 3)
   ─────────────────────────
   Timer triggers every N minutes
      │
      ├─ ChainSubmissionHostedService.ExecuteAsync()
      │  │
      │  ├─ Get recent chain entries (batch: 100)
      │  │
      │  ├─ ChainSubmitter.SubmitAsync()
      │  │  └─ POST /api/v1/chain/submit
      │  │     Request: { LicenseId, Entries[], SubmittedAt }
      │  │
      │  └─ Server Response
      │     └─ { Accepted: true, NewNonce: "guid..." }
      │
      ├─ NonceRotator.RotateAsync()
      │  └─ Update license.json
      │     "ServerNonce": "new-guid"
      │
      └─ Server stores audit trail
