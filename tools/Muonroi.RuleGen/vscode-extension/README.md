# Muonroi RuleGen VS Code Extension (Scaffold)

This scaffold adds command shortcuts for RuleGen flows:

- `Muonroi RuleGen: Extract All Rules`
- `Muonroi RuleGen: Merge Runtime Rules`
- `Muonroi RuleGen: Split Handler to Rules`

## Local Run

1. Open this folder in VS Code extension development host.
2. Press `F5`.
3. Use Command Palette and search `Muonroi RuleGen`.

## Requirement

`muonroi-rule` CLI must be available on PATH.
