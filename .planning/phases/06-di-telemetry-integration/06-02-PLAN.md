## Pipeline simplification (verified against source — overrides CONTEXT.md Decision 2 detail)

`LayoutEngine.LayoutAsync` ALREADY orchestrates layout + font pre-pass + image pre-pass internally. `MPdfService` must NOT instantiate `FontPipeline`/`ImagePipeline` directly (CONTEXT.md Decision 1 predates this verification). The real chain is:
1. Validate HTML byte length against `PdfConfigs.PdfLimits.MaxHtmlBytes` (early exit).
2. Linked CTS + `CancelAfter(MaxRenderDurationMs)`.
3. Start activity, set tags.
4. `IHtmlParser.ParseAsync(html, ct)` → `IParsedDocument`.
5. `ICssCascadeEngine.CascadeAsync(parsed, userStyleSheet: null, ct)` → `IStyledDocument`.
6. Policy gate: cast the styled doc to `IPdfDocumentContext` (the concrete `AngleSharpStyledDocument` implements both) and call `_cssPolicy.ValidateAsync((IPdfDocumentContext)styled, ct)`. If `!result.IsValid` throw `new PdfPolicyException(result.Violations)`.
7. `new LayoutEngine().LayoutAsync(styled, options, configs.Limits, fontResolver, resourceResolver, imageDecoder, ct)` → `IPositionedPageList`. Pass `null` for `fontResolver` when none is registered.
8. `_writer.WriteAsync(pages, options, destination, ct)` → `long byteCount`.
9. Record metrics; return `PdfRenderResult`.

`RenderAsync(string html, Stream destination, PdfRenderOptions options, CancellationToken cancellationToken)`:

2. HTML byte-length guard: `if (Encoding.UTF8.GetByteCount(html) > PdfConfigs.PdfLimits.MaxHtmlBytes) throw new PdfInputLimitException("HTML-MAX-BYTES", "MaxHtmlBytes", Encoding.UTF8.GetByteCount(html), PdfConfigs.PdfLimits.MaxHtmlBytes);`
3. `using var cts = CancellationTokenSource.CreateLinkedTokenSource(cancellationToken); cts.CancelAfter(TimeSpan.FromMilliseconds(_configs.Limits.MaxRenderDurationMs));` (PIPE-08, Decision 3). Thread `cts.Token` through EVERY downstream await.

   `activity?.SetTag(PdfTelemetryNames.TenantIdTag, tenantId);`
   (Use `options.TemplateId` only if that member exists on `PdfRenderOptions`; if not, use `string.Empty` and note in SUMMARY. Do not invent a property.)
5. `var sw = Stopwatch.StartNew();`
6. try:
   - `IParsedDocument parsed = await _htmlParser.ParseAsync(html, cts.Token).ConfigureAwait(false);`
   - `IStyledDocument styled = await _cascadeEngine.CascadeAsync(parsed, null, cts.Token).ConfigureAwait(false);`
   - `PolicyValidationResult policy = await _cssPolicy.ValidateAsync((IPdfDocumentContext)styled, cts.Token).ConfigureAwait(false);`
     - If `styled` is not assignable to `IPdfDocumentContext`, throw `InvalidOperationException` with a clear message (the engine's styled document must carry the policy context). Verify the cast compiles — `AngleSharpStyledDocument` implements both.
   - `if (!policy.IsValid) throw new PdfPolicyException(policy.Violations);`
   - `var layout = new LayoutEngine(); IPositionedPageList pages = await layout.LayoutAsync(styled, options, _configs.Limits, _fontResolver, _resourceResolver, _imageDecoder, cts.Token).ConfigureAwait(false);`
   - `long byteCount = await _writer.WriteAsync(pages, options, destination, cts.Token).ConfigureAwait(false);`
   - `sw.Stop();`
   - Record metrics:
     `PdfMetrics.OperationCounter.Add(1, new TagList { { PdfTelemetryNames.TenantIdTag, tenantId }, { "pdf.status", "ok" } });`
     `PdfMetrics.PageCountHistogram.Record(pages.PageCount, new TagList { { PdfTelemetryNames.TenantIdTag, tenantId } });`
     `activity?.SetStatus(ActivityStatusCode.Ok);`
   - `return new PdfRenderResult(pages.PageCount, byteCount, sw.Elapsed, string.Empty, _cssPolicy.Id, policy.Violations);`
     (Use `_cssPolicy.Id` for PolicyId if the `Id` member exists on `IPdfCssPolicy` — it does per ABST-04; if the member name differs, use the verified accessor. TemplateHash can be `string.Empty` for Phase 6 — content hashing is SEC-07/Phase 9 scope; note this in SUMMARY.)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTML input → MPdfService | Untrusted HTML; size-gated before parse, policy-gated after cascade |
| Singleton MPdfService → scoped ITenantContext | Scope boundary; must resolve per-call via IServiceProvider, never inject |
| MPdfService → caller destination Stream | Caller-owned stream; engine writes PDF bytes only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03 | Denial of Service | RenderAsync unbounded render | mitigate | Linked CTS + CancelAfter(MaxRenderDurationMs) cancels long renders with OperationCanceledException; cts.Token threaded through every await |
| T-06-04 | Denial of Service | oversized HTML input | mitigate | Encoding.UTF8.GetByteCount guard against MaxHtmlBytes before parsing — early exit with PdfInputLimitException |
| T-06-05 | Elevation of Privilege | scoped service captured in singleton | mitigate | ITenantContext resolved per-call via IServiceProvider.GetService; never constructor-injected (avoids captive-dependency scope violation) |
| T-06-06 | Repudiation | unattributed renders in telemetry | mitigate | Every span carries tenant.id and pdf.template_id; OperationCounter tagged with pdf.status ok/error |
| T-06-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installs; Microsoft.Extensions references resolved via CPM (versions already pinned in Directory.Packages.props) |
