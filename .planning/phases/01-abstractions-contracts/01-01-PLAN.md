## What This Is

`Muonroi.Pdf.Abstractions` is the pure-contracts assembly for the Muonroi.Pdf engine. It must target `netstandard2.0` (not `net8.0`) so it is referenceable by:
- Implementation packages (Phase 2–6, which target `net8.0`)
- The v0.2 source generator (which references it as an analyzer — analyzer references require netstandard2.0)

The assembly must have **zero NuGet package references** — all types it uses come from the netstandard2.0 BCL (`Stream`, `CancellationToken`, `ValueTask`, `ReadOnlyMemory<byte>`, `IReadOnlyList<T>`).

## PdfConfigs pattern (from REQUIREMENTS ABST-13, ABST-14)

```csharp
namespace Muonroi.Pdf.Abstractions;

public sealed class PdfConfigs
{
    public const string SectionName = "PdfConfigs";
    public Limits Limits { get; set; } = new();

    public sealed class Limits
    {
        public const long MaxHtmlBytes      = 8_388_608;   // 8 MB
        public const int  MaxDomDepth       = 256;
        public const int  MaxElementCount   = 100_000;
        public const long MaxImagePixels    = 25_000_000;
        public const int  MaxPages          = 1_000;
        public const long MaxRenderDurationMs = 15_000;
        public const int  MaxFontFiles      = 32;
    }
}
```

Limits are `const` (compile-time), NOT `{ get; set; }` properties. This satisfies ABST-14's "compile-time constants" requirement.
