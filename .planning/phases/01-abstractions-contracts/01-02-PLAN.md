## Opaque Seam Pattern

Each adapter interface uses opaque marker interfaces as input/output types. This prevents third-party library types from leaking through the seam boundary:

```
IHtmlParser.ParseAsync(string html) → IParsedDocument
                                           ↑ marker interface — impl holds AngleSharp.IDocument internally
ICssCascadeEngine.CascadeAsync(IParsedDocument, string?) → IStyledDocument
                                                                ↑ marker interface — impl holds AngleSharp.Css computed styles internally
IImageDecoder.Decode(ReadOnlySpan<byte>, string) → DecodedImage
                                                       ↑ sealed record — no library types
IPdfWriter.WriteAsync(IPositionedPageList, PdfRenderOptions, Stream) → ValueTask<long>
                          ↑ marker interface — layout impl holds PdfSharpCore page objects internally
```

Phase 2–5 implementation packages reference these seam types to implement the pipeline. Callers of `IMPdfService` never touch Engine types directly.

## Types available in netstandard2.0 BCL (use these only)

- `System.IO.Stream` — for `IPdfWriter.WriteAsync`
- `System.Threading.CancellationToken` — all async methods
- `System.Threading.Tasks.ValueTask<T>` — return type for async seam methods
- `System.ReadOnlySpan<byte>` — for `IImageDecoder.Decode`
- `System.ReadOnlyMemory<byte>` — for `DecodedImage.Data`
- `Muonroi.Pdf.Abstractions.PdfRenderOptions` — for `IPdfWriter.WriteAsync` (in same assembly)

GlobalUsings.cs already imports System, System.IO, System.Threading, System.Threading.Tasks — these are available without explicit usings.

## Exact signatures required (from CONTEXT.md Decision 3)

```csharp
// Marker interfaces
public interface IParsedDocument { }
public interface IStyledDocument { }
public interface IPositionedPageList { }

// Data record
public sealed record DecodedImage(int Width, int Height, ReadOnlyMemory<byte> Data, string ContentType);

// Adapter seams
public interface IHtmlParser
{
    ValueTask<IParsedDocument> ParseAsync(string html, CancellationToken ct = default);
}

public interface ICssCascadeEngine
{
    ValueTask<IStyledDocument> CascadeAsync(
        IParsedDocument doc,
        string? userStyleSheet,
        CancellationToken ct = default);
}

public interface IImageDecoder
{
    DecodedImage Decode(ReadOnlySpan<byte> data, string contentType);
}

public interface IPdfWriter
{
    ValueTask<long> WriteAsync(
        IPositionedPageList pages,
        PdfRenderOptions options,
        Stream destination,
        CancellationToken ct = default);
}
```

## Anti-patterns to avoid

- Do NOT include any `using AngleSharp`, `using SixLabors`, or `using PdfSharpCore` in any Engine/ file
- Do NOT add any NuGet references to `Muonroi.Pdf.Abstractions.csproj`
- Do NOT make `IParsedDocument`, `IStyledDocument`, or `IPositionedPageList` extend any base type — they are pure markers
- Do NOT make `DecodedImage` mutable — it is a `sealed record` (immutable by default)
- `IImageDecoder.Decode` is synchronous (no ValueTask) — image decoding is CPU-bound with no I/O at the seam level
