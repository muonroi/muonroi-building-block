```csharp
    public float PageMarginLeftPt => PageMargins.Left * Units.MmToPt;
```

## BoxTreeBuilder

Namespace: `Muonroi.Pdf.Internal.Layout`

The builder walks an IStyledNode tree and produces a BoxNode tree. Key logic:

1. **`Build(IStyledNode root) : BlockBox`** — entry point; creates root BlockBox from `<html>` or `<body>` element; walks children recursively
2. **`BuildNode(IStyledNode node) : BoxNode?`** — returns null for display:none; creates typed box based on display value
3. **`NormalizeChildren(List<BoxNode?> rawChildren) : List<BoxNode>`** — anonymous box generation per CSS 2.1 §9.2.1

Anonymous box rule: If a block container has mixed block-level + inline-level children, wrap all consecutive inline siblings in an AnonymousBox. Algorithm:
```
result = []
pending_inline = []
foreach child in rawChildren:
    if child is block-level (BlockBox, AnonymousBox, TableBox):
        if pending_inline.Count > 0:
            result.Add(new AnonymousBox { Children = pending_inline })
            pending_inline = []
        result.Add(child)
    else (inline-level: InlineBox, ReplacedBox):
        pending_inline.Add(child)
if pending_inline.Count > 0:
    result.Add(new AnonymousBox { Children = pending_inline })
return result
```

**CSS display values to box types:**
- `"block"`, `"list-item"`, `"flow-root"` → BlockBox
- `"inline"`, `"inline-block"` → InlineBox (inline-block treated as atomic inline)
- `"table"` → TableBox
- `"table-row-group"`, `"tbody"` → TableRowGroupBox (Body)
- `"table-header-group"`, `"thead"` → TableRowGroupBox (Header)
- `"table-footer-group"`, `"tfoot"` → TableRowGroupBox (Footer)
- `"table-row"`, `"tr"` → TableRowBox
- `"table-cell"`, `"td"`, `"th"` → TableCellBox
- `"none"` → null (node skipped)
- unrecognized → default to BlockBox

**CSS value resolution in BoxTreeBuilder** (applied to each node's style):
- Margin/Padding/Border: call `IComputedStyle.GetValue("margin-top")` etc.; parse with `ParseLength(val, containingBlockWidth)`.
  - For non-percent values: parse number + unit suffix (px, mm, cm, em, pt). `em` relative to `font-size`.
  - For `auto` margin: store 0f (margin collapsing is in BlockLayoutEngine, not here).
  - Percent: store -1f as sentinel (resolved against AvailableWidth during layout — see RESEARCH.md Pitfall 7).
- Width/Height: parse similarly; store -1f for "auto".
- FontSize: parse from `font-size` computed value, default 12f pt.
- PageBreak properties: read `page-break-before`, `page-break-after`, `page-break-inside` from computed style.
- For InlineBox: read font-family, font-weight (bold if "bold" or "700"+), font-style (italic), color.
- For TableCellBox: read `colspan` and `rowspan` attributes (not computed style — these are HTML attributes).
- For TableBox: read `border-spacing` from computed style.

**`ParseLength(string? val, float containingBlockWidth = 0f) : float`** helper:
- null or empty → 0f
- ends with "px" → float * PxToPt
- ends with "mm" → float * MmToPt
- ends with "cm" → float * CmToPt
- ends with "in" → float * InToPt
- ends with "pt" → float as-is
- ends with "em" → float * currentFontSize * PxToPt (approximation without real metrics)
- ends with "%" → return -1f (percent — resolved during layout)
- bare number → interpret as px (CSS computed values are unitless for 0, otherwise have units)

```csharp
namespace Muonroi.Pdf.Tests.Helpers;

internal sealed class FakeStyledNode : IStyledNode
{
    private readonly Dictionary<string, string> _styles;
    private readonly Dictionary<string, string> _attributes;

    public string LocalName { get; set; } = "div";
    public string? TextContent { get; set; }
    public bool IsElement { get; set; } = true;
    public bool IsText { get; set; }
    public List<IStyledNode> ChildList { get; } = new();

    public FakeStyledNode(string localName = "div",
        Dictionary<string, string>? styles = null,
        Dictionary<string, string>? attributes = null)
    {
        LocalName = localName;
        _styles = styles ?? new();
        _attributes = attributes ?? new();
    }

    public IComputedStyle Style => new FakeComputedStyle(_styles);
    public IReadOnlyList<IStyledNode> Children => ChildList;
    public string? GetAttribute(string name) => _attributes.GetValueOrDefault(name);
}

internal sealed class FakeComputedStyle : IComputedStyle
{
    private readonly Dictionary<string, string> _values;

    public FakeComputedStyle(Dictionary<string, string> values)
        => _values = values;

    public string? GetValue(string property)
        => _values.TryGetValue(property, out string? v) ? v : null;

    public bool HasProperty(string property)
        => _values.ContainsKey(property);
}
```
