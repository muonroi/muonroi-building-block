```csharp
    private static bool IsBfcRoot(BoxNode box, IComputedStyle? style)
    {
        // BFC roots per CONTEXT.md Decision 6:
        // - root element (LocalName == "html" or box.Display == "block" at depth 0)
        // - overflow: hidden
        // - display: inline-block
        // - table cells (TableCellBox)
        // - (float: never appears — policy gate rejects in Phase 2)
    }

    private static float CollapseMargins(float a, float b)
    {
        // Positive-only: max(a, b)
        // With negatives: max(positives) + min(negatives)
        float positive = MathF.Max(MathF.Max(a, 0f), MathF.Max(b, 0f));
        float negative = MathF.Min(MathF.Min(a, 0f), MathF.Min(b, 0f));
        return positive + negative;
    }
}
```

### Block Layout Algorithm (CSS 2.1 §8 + §9)

```
LayoutBlockChildren(box, context, output, pageIndex):
  startY = context.CurrentY
  prevMarginBottom = 0f  // for adjacent sibling collapsing

  for i, child in box.Children:
    resolve child.Width if == -1f:
      child.Width = context.AvailableWidth - child.MarginLeft - child.MarginRight
                    - child.PaddingLeft - child.PaddingRight
                    - child.BorderLeft - child.BorderRight
    resolve child.Width if contains % sentinel:
      child.Width = context.AvailableWidth * percentValue / 100f - ...

    // Margin collapsing:
    // Case 1: Adjacent sibling — collapse prevMarginBottom with child.MarginTop
    if i > 0 and not IsBfcRoot(child):
      effectiveMarginTop = CollapseMargins(prevMarginBottom, child.MarginTop)
      // Remove already-applied prevMarginBottom from cursor, apply collapsed value
      context.CurrentY -= prevMarginBottom
      context.CurrentY += effectiveMarginTop
    else:
      context.CurrentY += child.MarginTop

    // Case 2: Parent-child collapsing (first child only):
    // If parent has no top border/padding, parent.MarginTop collapses with child.MarginTop
    // (handled when first child is processed: the parent's margin was already applied by caller)

    childX = context.PageMarginLeftPt + box.PaddingLeft + child.MarginLeft
    childY = context.CurrentY

    // Layout the child recursively based on its type
    childHeight = DispatchLayout(child, context, output, pageIndex)

    output.Add(new PositionedElement {
        Position = new Rect(childX, childY, child.Width, childHeight),
        Source = child,
        PageIndex = pageIndex
    })

    context.CurrentY += childHeight + child.PaddingBottom + child.BorderBottom
    prevMarginBottom = child.MarginBottom

  // Apply last margin (not collapsed with anything)
  context.CurrentY += prevMarginBottom

  return context.CurrentY - startY
```

**Case 3: Empty block collapsing** — if box.Children is empty and box has no border/padding/height, its MarginTop and MarginBottom collapse together. Handle in caller after getting 0 height return.

**Percent width resolution**: When `child.Width == -1f`, resolve to `context.AvailableWidth - horizontal box model`. Store back on child.Width before laying out children. When encountering the -1f percent sentinel from BoxTreeBuilder (which stored -1f for percent), the percent value is unavailable without the source style. Solution: BoxTreeBuilder should store a separate `WidthPercent : float` property (0–100f, 0 means no percent) on BoxNode. Add this property to BoxNode if not already present, or use a flag/second field.

Alternative simpler approach: Store the raw CSS width string on BoxNode as `string? WidthRaw` and parse it during layout. The layout engine re-parses the raw CSS width value when it needs to. This is the cleanest approach — add `string? WidthRaw` and `string? HeightRaw` to BoxNode (nullable strings, null means not set).

**Overflow overflow:hidden BFC root**: For the purpose of Phase 3, check `box.Source?.Style.GetValue("overflow") == "hidden"` to detect BFC roots. This requires IStyledNode reference on BoxNode (BoxNode.Source is already defined in Plan 03).

### Line Box Algorithm

1. Gather all inline children (text runs + inline-blocks)
2. For each text run: measure width using `context.TextMetrics.GetCharWidth()` × text length
3. Break text into line-break opportunities using `BreakIntoWords(text)` — split on spaces and Unicode break characters
4. Accumulate words into the current line until the line would exceed `context.AvailableWidth`
5. When line is full: commit line box, advance Y by line height
6. **Baseline computation** (per CONTEXT.md Decision 7):
   - `lineAscender = max(context.TextMetrics.GetAscender(font, size) for each inline box in line)`
   - Each inline box's Y = lineY + (lineAscender - ascender_of_this_box)  [baseline alignment]
   - `vertical-align: top` → Y = lineY (top of line box)
   - `vertical-align: middle` → Y = lineY + (lineHeight - boxHeight) / 2
   - `vertical-align: bottom` → Y = lineY + lineHeight - boxHeight

**Word breaking heuristic for Phase 3**: Split on `' '`, `'\t'`, `'\n'`, `'​'` (zero-width space). This handles Latin. Vietnamese uses UAX#14 which is more complex — the default word-boundary approach is acceptable for Phase 3 (full shaping is Phase 4). Document in KNOWN-DEVIATIONS.md if UAX#14 specifics differ.

## ANTI-PATTERNS (from RESEARCH.md)

- Do NOT implement margin collapsing as `a + b` — it is `max(a, b)` for positives
- Do NOT forget parent-child margin collapsing (Case 2) — causes double spacing before first paragraph
- Do NOT resolve percent widths in BoxTreeBuilder — resolve in BlockLayoutEngine when laying out
- Do NOT use double arithmetic — float throughout

    Line commit: for each line box:
    - Compute lineAscender = max GetAscender over all inline boxes in this line
    - Compute lineHeight = max GetLineHeight over all inline boxes
    - For each inline box in line, compute its y offset based on vertical-align:
      - "baseline" (default): yOffset = lineAscender - GetAscender(this box)
      - "top": yOffset = 0
      - "middle": yOffset = (lineHeight - GetLineHeight(this box)) / 2
      - "bottom": yOffset = lineHeight - GetLineHeight(this box)
    - Add PositionedElement for each inline box at (lineStartX + boxOffsetX, lineY + yOffset, boxWidth, boxHeight)
    - Advance lineY by lineHeight

    Total height returned = sum of all line heights.

    PITFALL: Ensure no infinite loop when a single word is wider than the available line width. The "force-break after word regardless" rule handles this.
