### Column Sizing (CSS 2.1 §17.5.2)

Step 1 — Determine column count from the row with most cells (accounting for colspan).

Step 2 — For `table-layout: fixed`:
- Use explicit width attributes/styles from the first row's cells. Columns without explicit width divide remaining space equally.

Step 3 — For `table-layout: auto`:
```
// Pass A: size non-spanning (colspan=1) columns
for each column c:
    minWidth[c] = max(min-content width of all non-spanning cells in column c)
    prefWidth[c] = max(preferred-content width of all non-spanning cells in column c)
    // min-content ≈ longest single word width; preferred ≈ full text width (no wrapping)
    // Using ITextMetrics via EstimatedTextMetrics: each char = fontSize * 0.6f

// Pass B: distribute spanning cells
for colspan = 2 to maxColspan:
    for each spanning cell (colspan == N):
        spanSum = sum(prefWidth[c] for c in spanned columns)
        if cell.preferred-content-width > spanSum:
            excess = cell.preferred-content-width - spanSum
            distribute excess proportionally to spanned columns

// Pass C: scale to available width
totalPreferred = sum(prefWidth)
if totalPreferred <= availableWidth:
    // Distribute extra space proportionally
    for each c: colWidth[c] = prefWidth[c] / totalPreferred * availableWidth
else:
    // Scale down proportionally, respecting minimum widths
    scale = availableWidth / totalPreferred
    for each c: colWidth[c] = max(minWidth[c], prefWidth[c] * scale)
```

### Row Layout with Rowspan

```
// Pass 1: layout each row assuming rowspan=1 for all cells
for each row r:
    rowHeight[r] = 0f
    for each cell in row (not spanning-continuation):
        cellWidth = sum(colWidth[c] for c in cell's columns) + (colspan-1) * borderSpacing
        // layout cell content using _blockEngine
        cellHeight = layoutCellContent(cell, cellWidth, context)
        if cell.Rowspan == 1:
            rowHeight[r] = max(rowHeight[r], cellHeight)

// Pass 2: adjust row heights for rowspan > 1 cells
for each cell with Rowspan > 1:
    spanHeight = sum(rowHeight[r] for r in spanned rows) + (rowspan-1) * borderSpacing
    if cellHeight > spanHeight:
        // Distribute excess to spanned rows proportionally
        excess = cellHeight - spanHeight
        for each spanned row r: rowHeight[r] += excess / rowspan
```

### Cell Positioning

After column widths and row heights are computed, iterate all cells to assign Rect positions:
```
currentY = tableOriginY
for each row group (header/body/footer):
    for each row:
        currentX = tableOriginX + borderSpacing
        for each cell:
            cellX = currentX + sum(colWidth[0..cellColumnIndex-1]) + cellColumnIndex * borderSpacing
            cellY = currentY + borderSpacing
            output.Add(PositionedElement { Position = Rect(cellX, cellY, cellWidth, cellHeight), ... })
        currentY += rowHeight + borderSpacing
```

### min-content and preferred-content width approximation (EstimatedTextMetrics)

For min-content: longest "word" (split on spaces) × fontSize × 0.6f × maxFontSize_in_cell
For preferred: full text length × fontSize × 0.6f (assume single line)

This is accurate enough for Phase 3 unit tests. Phase 4 with real metrics will be more precise.

### Page Break Algorithm

Design: Layout engines (Block, Inline, Table) produce PositionedElements with `PageIndex = 0` initially. PaginationEngine then scans the elements in document order (sorted by Y position), inserting page breaks when:
1. A PositionedElement's source has `PageBreakBefore == "always"` → force break before
2. A PositionedElement's Y + Height exceeds current page's body height → natural break
3. A PositionedElement's source has `PageBreakInside == "avoid"` → attempt to keep on same page (but break anyway if element.Height > pageBodyHeight — RESEARCH.md Pitfall 4)

When a break occurs:
- Assign all elements before break to current page
- Start new page
- Translate subsequent elements' Y coordinates relative to the new page origin

### Page Dimensions

Page body dimensions (excluding margin boxes):
```
pageWidth  = PdfPageSizeDimensions.Get(options.PageSize).Width (or Height if landscape)
pageHeight = PdfPageSizeDimensions.Get(options.PageSize).Height (or Width if landscape)
topMarginPt    = (pageRule?.Margins.Top ?? options.Margins.Top) * Units.MmToPt
bottomMarginPt = (pageRule?.Margins.Bottom ?? options.Margins.Bottom) * Units.MmToPt
leftMarginPt   = (pageRule?.Margins.Left ?? options.Margins.Left) * Units.MmToPt
rightMarginPt  = (pageRule?.Margins.Right ?? options.Margins.Right) * Units.MmToPt
bodyHeight = pageHeight - topMarginPt - bottomMarginPt - headerHeight - footerHeight
bodyWidth  = pageWidth - leftMarginPt - rightMarginPt
```

**Precedence rule for margins** (CONTEXT.md Decision 3):
1. PdfRenderOptions.Margins if non-default overrides @page margins
2. @page margins override default 10mm baseline
3. PdfRenderOptions.Header/Footer overrides IPageRule.TopMarginBoxHtml/BottomMarginBoxHtml

### Header/Footer per Page

For each page:
- If header HTML is provided (pageRule?.TopMarginBoxHtml or options.Header?.Html), render as mini-block at Y = topMarginPt, height = headerHeight
- If footer HTML is provided, render at Y = pageHeight - bottomMarginPt - footerHeight

Header/footer rendering: create a simple InlineBox from the HTML text (stripped of tags for Phase 3 — full HTML parsing of header is deferred). Height = one line box. Position at top/bottom margin box.

### CSS Counter Substitution

Counter substitution happens during PaginationEngine, not during BoxTreeBuilder. Scan for InlineBox.TextContent containing:
- `counter(page)` → replace with `(pageIndex + 1).ToString()`
- `counter(pages)` → replace with `context.TotalPages.ToString()` (0 in pass 1, real count in pass 2)

Use `string.Replace` on InlineBox.TextContent — simple and sufficient for Phase 3.

### MaxPages Check

After computing all page breaks in pass 1:
```csharp
if (result.PageCount > limits.MaxPages)
    throw new PdfInputLimitException(
        $"Document produces {result.PageCount} pages which exceeds the MaxPages limit of {limits.MaxPages}.");
```

This check happens INSIDE `LayoutEngine.Layout()` after pass 1, before pass 2. PaginationEngine returns without checking — the check is LayoutEngine's responsibility (Plan 07).
