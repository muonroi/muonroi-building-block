<objective>
Generalize the Phase 14 single-`rotate()` transform support to the full CSS 2D affine set
(translate/translateX/translateY, scale/scaleX/scaleY, rotate, skew/skewX/skewY, matrix(), and
multi-function chains), composed left-to-right into ONE 2×3 matrix → one CTM per element. Widen the
`LegacyPrintPolicy` transform gate from single-rotate to a fail-loud affine-function allowlist.

Implements ROADMAP Phase 15 Success Criterion 2 (transform) and contributes to SC3 (no regression /
byte-identical / PerfGate). Locked decisions: D-01 (full affine set, single composed matrix), D-02
(widen policy gate, fail-loud on unknown token, inline-style fallback applies), D-03 (box-center
pivot only — CSS default `transform-origin: 50% 50%`; transform-origin property deferred).

Purpose: Phase 14 infrastructure (`AppendCm`, the Tm-baking math, `RotationGroup`/pivot resolution)
is already generic — the only rotate-specific code is `RotMatrix` and the `RotationGroup.AngleDegrees`
carrier. This plan replaces those with a general composed-matrix path; no new PDF operators are added.

Output: `TransformGroup` carrier (double[6] matrix), `TryParseTransformMatrix` parser, generalized
writer emission, widened policy gate, and flipped/new policy + render tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller-supplied HTML/CSS -> parser/policy | Untrusted `transform` value strings cross here before any layout/writer code runs |
| layout box tree -> PDF writer | Composed `double[6]` matrix flows into content-stream `cm`/`Tm` emission |

This is an offline, pure-managed PDF library with no network/auth surface. The realistic threat is
malformed/pathological CSS transform input causing unhandled exceptions, resource exhaustion, or a
policy bypass that lets an unsupported construct reach the writer.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15.01-01 | Tampering / Elevation | LegacyPrintPolicy transform gate | mitigate | `IsAffineTransform` uses an explicit allowlist (`AllowedAffineFunctions`) and rejects any unknown function name fail-loud (D-02); the gate is called in BOTH the computed-style and inline-`style=""` paths so a GetComputedStyle throw cannot bypass it (P1). |
| T-15.01-02 | Denial of Service | TryParseTransformMatrix tokenizer | mitigate | Regex `(\w+)\(([^)]*)\)` is non-backtracking-prone (no nested quantifiers on the same group); a malformed value returns false (no transform) rather than looping. Reject non-numeric args via `AreNumericArgs` before any Math.* call (avoids NaN/Infinity propagating to `cm`). |
| T-15.01-03 | Tampering | TryParseTransformMatrix arg parsing | mitigate | `double.TryParse` with `CultureInfo.InvariantCulture`; unparseable args -> false. No `Convert.ToDouble` (throws). |
| T-15.01-04 | Information Disclosure / Repudiation | No Silent Catch | mitigate | Any catch added in parse/policy logs module + operation + `ex.Message` per project rule; no empty `catch {}`. |
| T-15.01-05 | Spoofing | n/a (no auth surface) | accept | Offline library; no identity/authn in scope. |
</threat_model>
