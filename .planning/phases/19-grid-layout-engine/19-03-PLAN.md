  <behavior>
    <!-- Behaviour is asserted as positions/track sizes in Plan 04; here, encode the algorithm's contract. -->
    - Column track sizing: resolve TemplateColumns into pixel widths against the container content width (AvailableWidth or explicit Width). Fixed Length tracks take their points; Percent tracks = pct × axisSize; Auto tracks = max content width of items placed in that track (max-content pass via _blockEngine.Layout); fr tracks split the remaining free space (axisSize − Σfixed/percent/auto − totalColumnGaps) proportionally to their Fraction; MinMax(min,max) clamps the resolved size into [resolve(min), resolve(max)] (a `1fr` max participates in the fr distribution capped by it; a fixed min sets the floor).
    - Row track sizing: same algorithm against the container content height (explicit Height else content-driven sum). Auto/content rows sized by the measured content height of items in that row.
    - Explicit placement: grid-column / grid-row "N" → 1-based line N; "A / B" → start line A, end line B; "span K" → spans K tracks from the auto/explicit start; negative line numbers count from the end (line −1 = last line). grid-area "r-start / c-start / r-end / c-end" shorthand parses to row/col spans; a single name resolves via grid-template-areas.
    - Named-area placement: grid-area:"main" resolves to the bounding rectangle (min/max row, min/max col) of all cells labelled "main" in TemplateAreas.
    - Auto-placement (sparse, D-01): items without explicit placement flow into the next free cell per grid-auto-flow (row = fill columns left→right then next row; column = fill rows top→bottom then next column). Cells occupied by explicitly-placed items are skipped. Implicit tracks (beyond the explicit template) are created and sized by grid-auto-rows / grid-auto-columns (null → auto).
    - Cell positioning: each item's cell rect = (origin + Σ preceding track sizes + Σ preceding gaps) for x/y, and (Σ spanned track sizes + interior gaps) for width/height. justify-self / align-self (fall back to container justify-items / align-items) position the item WITHIN its cell (start/end/center/stretch — stretch fills the cell). justify-content / align-content position the WHOLE track group within the container when tracks don't fill it (start/end/center/space-between/space-around/space-evenly/stretch).
    - Recursion: each item laid out via _blockEngine.Layout into the cell rect (set box.Width/Height to the cell or stretched size, save/restore WidthRaw — mirror FlexLayoutEngine.EmitItem); nested grid/flex/block/table compose.
    - Returns the container's total height (Σ row track sizes + row gaps, or explicit Height); advances context.CurrentY = startY + height.
  </behavior>
