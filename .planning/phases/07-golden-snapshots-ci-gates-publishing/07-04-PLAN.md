<objective>
Add the PERF-01/PERF-02 gate as an informational, dev-machine Stopwatch test (with warmup, best-of-N warm) over a ~50 KB reference template. Per locked decision 2, the assertion uses a GENEROUS ceiling (cold <=1500 ms, warm <=400 ms) so it never flakes on slow CI hardware; the tight 300/80 ms target is recorded as a comment and is the developer-machine goal. The test is skippable (`MUONROI_SKIP_PERF=1`) and excluded from the pre-publish gate via `Category=SlowIntegration`.

Purpose: PERF-01/02 are hardware-dependent. A literal 300/80 ms CI gate produces false failures on shared runners (RESEARCH Pitfall 4 / A5). This delivers a real, runnable perf signal without making absolute ms a hard CI gate.
Output: reference template + perf gate test; runs green within the generous ceiling.
</objective>
