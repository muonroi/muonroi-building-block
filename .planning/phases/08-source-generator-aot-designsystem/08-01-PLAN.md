Create `src/Muonroi.Pdf.SourceGenerators/PdfTemplateGenerator.cs` in namespace `Muonroi.Pdf.SourceGenerators`:

The generator must implement `IIncrementalGenerator` (NOT `ISourceGenerator` — V1 is deprecated).

`Initialize` method structure:
1. `context.RegisterPostInitializationOutput` — emit a copy of `PdfTemplateAttribute` as `PdfTemplateAttribute.g.cs` into every consumer's compilation (use the exact same attribute source text as in `Muonroi.Pdf.Abstractions/PdfTemplateAttribute.cs`; namespaced as `Muonroi.Pdf.Abstractions`). This ensures the attribute type resolves even if the consumer does not reference Abstractions directly.

2. `IncrementalValuesProvider<PdfTemplateModel>` via `context.SyntaxProvider.ForAttributeWithMetadataName`:
   - `fullyQualifiedMetadataName`: `"Muonroi.Pdf.Abstractions.PdfTemplateAttribute"`
   - predicate: node is `ClassDeclarationSyntax or RecordDeclarationSyntax`
   - transform: extract `PdfTemplateModel { TypeFullName, TypeNamespace, TypeName, TemplateId, TemplateResourceName, ContainingNamespace }`
   - `.Where(m => m is not null)!`

3. `context.RegisterSourceOutput(models, static (spc, model) => EmitRenderer(spc, model))` — emits two files per model:
   a. `{TypeName}PdfRenderer.g.cs` — sealed class `{TypeName}PdfRenderer : IMPdfRenderer<{FullTypeName}>`:
      - Constructor injects `IMPdfService _service`
      - `TemplateId` property returns the templateId string literal
      - `RenderAsync` method:
        - If `TemplateResourceName` is not null: declare `string html = context.AdditionalFiles` lookup in a static field initialized via `System.Reflection.Assembly.GetExecutingAssembly().GetManifestResourceStream` — NO. WRONG approach. Instead: the SG reads the AdditionalFile text at SOURCE GENERATION TIME (inside the transform via `ctx.AdditionalTexts`) and inlines the HTML content as a C# verbatim string literal. Token placeholders in the HTML using `{{Property}}` syntax are rewritten to `{model.Property}` interpolation. This is the critical step for the 3x speedup.
        - If `TemplateResourceName` is null: inline `string html = "";` (stub renderer).
        - Call: `return _service.RenderAsync(html, destination, options ?? new global::Muonroi.Pdf.Abstractions.PdfRenderOptions(), cancellationToken);`
   b. `{TypeName}PdfRendererServiceExtensions.g.cs` — static class with extension method `AddPdfRenderer{TypeName}(this IServiceCollection services)` that calls `services.TryAddSingleton<IMPdfRenderer<{FullTypeName}>, {TypeName}PdfRenderer>()`. This satisfies SG-03 (no call-site change — just reference the SG project, the DI extension is auto-available).

Template token rewriting in the transform: iterate `AdditionalTexts` to find the file matching `TemplateResourceName`. Read its text. Replace `{{(\w+)}}` occurrences with `{model.$1}`. Escape existing `{` / `}` characters in the HTML that are NOT token placeholders by doubling them (`{` → `{{`, `}` → `}}`). The resulting string goes into the C# interpolated string verbatim (`$"""`).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Consumer HTML template → SG AdditionalFiles | Template HTML is read at build time by the generator and inlined as C# code; malicious template tokens cannot execute arbitrary code but could inject valid C# into generated files |
| Generated renderer → IMPdfService.RenderAsync | Generated HTML string still passes through DefaultStrictPolicy at render time — script injection and forbidden CSS are caught there |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering | PdfTemplateGenerator token rewriting | mitigate | Token rewriting only substitutes `{{Word}}` patterns (word chars only); arbitrary expressions cannot be injected. Non-token `{`/`}` chars are escaped to prevent C# interpolation syntax breakage. |
| T-08-02 | Tampering | Generated DI extension | accept | Extensions call `TryAddSingleton` — cannot override an existing registration; no elevation possible |
| T-08-SC | Tampering | NuGet package installs | accept | No new NuGet packages added in this plan; Microsoft.CodeAnalysis.* are already pinned in CPM; no slopcheck needed |
</threat_model>
