## DefaultStrictPolicy allowed CSS (from src/Muonroi.Pdf.Governance/Policies/DefaultStrictPolicy.cs)

ALLOWED:
- `display: block`, `display: table`, `display: table-row`, `display: table-cell`, `display: inline`, `display: inline-block`
- `position: static`, `position: relative`
- `border-collapse: separate` (NOT collapse — collapse is rejected with structured diagnostic)
- `margin`, `padding`, `border`, `width`, `height`, `color`, `background-color`, `font-family`, `font-size`, `font-weight`, `font-style`
- `text-align`, `vertical-align`, `line-height`
- `@page` rules, `page-break-before`, `page-break-after`, `page-break-inside`

FORBIDDEN (will throw PdfPolicyException at render time):
- `display: flex` — ruleId: `forbidden.display.flex`
- `display: grid` — ruleId: `forbidden.display.grid`
- `float: any` — ruleId: `forbidden.float`
- `position: absolute`, `position: fixed`, `position: sticky`
- `@keyframes` / `animation` — ruleId: `forbidden.animation`
- `transition` — ruleId: `forbidden.transition`
- External `@import` (URIs)
- `<script>` elements — ruleId: `forbidden.script-element`

Use `display: table` / `display: table-row` / `display: table-cell` for ALL two-column and multi-column layouts.
Use `display: block` with explicit `width` percentages for sidebars.
NEVER use float-based layout.

## Template token convention

Templates use `{{TokenName}}` placeholders (double braces). At render time the caller
substitutes tokens before passing HTML to IMPdfService, OR the SG-generated renderer
inlines them via C# interpolation. Design system templates must show realistic placeholder
structure matching the model shape consumers will provide.
