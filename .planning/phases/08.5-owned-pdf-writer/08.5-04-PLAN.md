## Engine assets (from RESEARCH.md §Gap 3)

- `PositionedPageList.Images`: `IReadOnlyDictionary<string, DecodedImage>` — keyed by img.Src.
- `DecodedImage`: `sealed record(int Width, int Height, ReadOnlyMemory<byte> Data, string ContentType)`.
- `PureImageDecoder` detects JPEG (magic `FF D8`) and PNG (magic `89 50 4E 47`).

## JPEG XObject structure

```
<< /Type /XObject /Subtype /Image
   /Width W /Height H
   /ColorSpace /DeviceRGB
   /BitsPerComponent 8
   /Filter /DCTDecode
   /Length N >>
stream
... raw JPEG bytes (DecodedImage.Data verbatim) ...
endstream
```
No transcoding, no buffer copy beyond the existing `ReadOnlyMemory<byte>` in `Data`.

## PNG XObject structure (8-bit RGB)

PNG IDAT data is a single zlib datastream (RFC 1950 — zlib-wrapped, per the PNG spec), NOT raw DEFLATE. Concatenate ALL IDAT chunk payloads first (the zlib stream may be split across multiple IDAT chunks), THEN inflate the concatenated bytes once using `System.IO.Compression.ZLibStream` (NOT DeflateStream — DeflateStream lacks the zlib header/trailer and will fail/corrupt). The inflated output = raw filtered scanlines (each row prefixed with a 1-byte filter type). Apply PNG filter reverse (None/Sub/Up/Average/Paeth) row-by-row to reconstruct raw RGB pixels — this un-filter step is mandatory; concatenating filtered rows directly produces a corrupt image. Then FlateDecode-compress the raw pixels with `ZLibStream` for embedding. [Correction applied from 08.5-RESEARCH-VERIFY.md item #2/#3 — RESEARCH.md had the zlib/DEFLATE direction backwards.]

Scope: 8-bit RGB PNG only. Detect bit depth and color type from the IHDR chunk (bytes 24–25 of the PNG file: bit_depth at offset 24, color_type at offset 25). If color_type != 2 (RGB) or bit_depth != 8, throw `PdfFormatException($"Unsupported PNG: color_type={colorType} bit_depth={bitDepth}. Only 8-bit RGB PNG is supported.")`.

```
<< /Type /XObject /Subtype /Image
   /Width W /Height H
   /ColorSpace /DeviceRGB
   /BitsPerComponent 8
   /Filter /FlateDecode
   /Length N >>
stream
... FlateDecode(raw RGB scanlines) ...
endstream
```

## Content stream image operator

For each `ReplacedBox` element at page position `(el.Position.X, el.Position.Y)` with `(el.Position.Width, el.Position.Height)`:

```
q
{width} 0 0 {height} {pdfX} {pdfY} cm
/Im{index} Do
Q
```

Where:
- `pdfX = el.Position.X` (points from left)
- `pdfY = pageHeight - el.Position.Y - el.Position.Height` (flip Y: PDF origin is bottom-left)
- `width` and `height` are in PDF points matching the CSS-laid-out size

Image XObject names: /Im0, /Im1, /Im2, ... assigned in the order images appear across all pages. Use a `List<(string ResourceName, int ObjectId)>` (same pattern as font resource list from Task 03).
