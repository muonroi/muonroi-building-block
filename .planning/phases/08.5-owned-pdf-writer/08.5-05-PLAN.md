## Determinism invariants the owned writer must satisfy (from RESEARCH.md §Gap 4)

- Fixed `/ID [<000000000000000000000000000000000000><000000000000000000000000000000000000>]`
- Fixed `/CreationDate (D:20000101000000Z)` and `/ModDate (D:20000101000000Z)`
- Fixed subset prefix `AAAAAA+`
- `%PDF-1.7` header + binary comment `%\xE2\xE3\xCF\xD3`
- Stable object ID assignment (sequential, declaration order, same for identical input)
- Stable font resource names (List-ordered, from Task 03)
- `/W` widths array emitted in ascending GID order (SortedGids, from Task 01)
- No process-lifetime static mutable state in OwnedPdfWriter

## NormalizeForDeterminism

`PdfSharpCoreWriter.NormalizeForDeterminism` is a regex pass that patches random tokens (subset prefix, /ID bytes, date strings) in PdfSharpCore output post-hoc. OwnedPdfWriter emits deterministic tokens natively — no such pass should be needed. Confirm by checking: if DeterminismTests pass WITHOUT any `NormalizeForDeterminism`-equivalent call in OwnedPdfWriter, this is confirmed.
