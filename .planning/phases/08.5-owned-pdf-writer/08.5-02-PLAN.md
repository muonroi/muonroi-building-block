## CID font object structure (exact, from RESEARCH.md §Gap 2)

### Type0 font dict
```
<< /Type /Font
   /Subtype /Type0
   /BaseFont /AAAAAA+FamilyName
   /Encoding /Identity-H
   /DescendantFonts [ N 0 R ]
   /ToUnicode M 0 R
>>
```

### CIDFont dict (descendant)
```
<< /Type /Font
   /Subtype /CIDFontType2
   /BaseFont /AAAAAA+FamilyName
   /CIDSystemInfo << /Registry (Adobe) /Ordering (Identity) /Supplement 0 >>
   /DW 1000
   /W [ gid1 [w1] gid2 [w2] ... ]
   /FontDescriptor P 0 R
   /CIDToGIDMap /Identity
>>
```

/W sparse format: each entry is `gid [width]` as a single-element array. GIDs from SortedGids; widths from `hmtx` in SubsetBytes via BuildGidToAdvanceMap (already in spike). PDF units = round(advance * 1000 / unitsPerEm).

### FontDescriptor
```
<< /Type /FontDescriptor
   /FontName /AAAAAA+FamilyName
   /Flags 4
   /FontBBox [llx lly urx ury]
   /ItalicAngle 0
   /Ascent <ascender>
   /Descent <descender>
   /CapHeight <capHeight>
   /StemV 80
   /FontFile2 Q 0 R
>>
```

Font metrics: read from OS/2 table in SubsetBytes (sTypoAscender, sTypoDescender, sCapHeight) and head table (unitsPerEm). Fall back to SixLaborsTextMetrics.GetAscender/GetDescender if OS/2 parse fails. Scale to PDF units: round(value * 1000 / unitsPerEm).

FontBBox: from OS/2 (sTypoAscender for ury, sTypoDescender for lly) or head table bounding box (xMin,yMin,xMax,yMax). Use [0 lly 1000 ury] as a safe approximation if exact bbox is unavailable.

### FontFile2 stream
```
<< /Length N /Length1 N /Filter /FlateDecode >>
stream … subset TTF bytes (FlateDecode-compressed) … endstream
```
/Length1 = uncompressed length of SubsetBytes. /Length = compressed length. FlateDecode via ZLibStream (Task 03 provides the compression helper, but FontFile2 needs it too — implement the compress helper in this task if Task 03 has not landed, or share a private static method).

### ToUnicode CMap stream
Template (emit as a stream object with /Length):
```
/CIDInit /ProcSet findresource begin
12 dict begin
begincmap
/CIDSystemInfo << /Registry (Adobe) /Ordering (UCS) /Supplement 0 >> def
/CMapName /Adobe-Identity-UCS def
/CMapType 2 def
1 begincodespacerange
<0000> <FFFF>
endcodespacerange
N beginbfchar
<GGGG> <UUUU>
...
endbfchar
endcmap
CMapName currentdict /CMap defineresource pop
end
end
```
GGGG = 4-digit uppercase hex new GID. UUUU = 4-digit uppercase hex Unicode codepoint (BMP only; for supplementary planes use surrogate pair notation per PDF spec, but Vietnamese is entirely BMP).

## Content stream GID encoding

Replace the spike's `AppendPdfString(text)` with `AppendGidString(text, fontInfo)`:
1. For each char `c` in the text run, look up `cp = (int)c`, then `oldGid` via the cmap-derived cp→oldGid map (already in spike as `BuildCpToGidMap` fallback, but prefer `OldToNewGid` from Task 01 composed with the cp→oldGid reverse map).
2. Emit each GID as a 2-byte big-endian hex pair: `<GGGG>`. Multiple glyphs in a run can be concatenated in one hex string: `<GGGGGGGG...>`.
3. The TJ operator takes an array: `[ <GGGG> ] TJ` for a single glyph or `[ <GGGGGGGG> -spacing <GGGG> ] TJ` for runs with inter-word spacing.
