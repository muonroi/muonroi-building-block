## Re-baseline mechanism (from RESEARCH.md §Gap 5)

`GoldenPdf.cs` UpdateMode:
```csharp
string? v = Environment.GetEnvironmentVariable("MUONROI_UPDATE_SNAPSHOTS");
bool UpdateMode = v == "1" || v?.Equals("true", OrdinalIgnoreCase) == true;
// When UpdateMode == true:
File.WriteAllBytes(Path.Combine(sourceDir, caseName + ".pdf"), actual);
```
Files are written to the SOURCE tree (not bin/), making them committable.

## Re-baseline command

Windows PowerShell (no -m:1 -nodereuse:false per host caveat):
```
$env:MUONROI_UPDATE_SNAPSHOTS = "1"
dotnet test tests/Muonroi.Pdf.Tests --filter "Category!=SlowIntegration" -c Release
Remove-Item env:MUONROI_UPDATE_SNAPSHOTS
```

This writes new .pdf files to `tests/Muonroi.Pdf.Tests/TestResources/Golden/`.
