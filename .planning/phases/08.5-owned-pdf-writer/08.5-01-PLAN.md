## Current TrueTypeFontSubsetter shape (from RESEARCH.md)

`TrueTypeFontSubsetter` is `internal sealed`. `BuildSubsetFont` computes `Dictionary<ushort,ushort> oldToNew` and `ushort[] sortedGids` internally (used to rebuild glyf, loca, hmtx, cmap tables in the subset TTF). These are currently local variables discarded after the method returns `ReadOnlyMemory<byte>` (the subset TTF bytes).

`EmbeddedFontInfo` currently carries:
- `SubsetBytes: ReadOnlyMemory<byte>` — the subset TTF
- `UsedCodepoints: IReadOnlySet<int>` — Unicode codepoints included

`FontPipeline` calls `TrueTypeFontSubsetter.Subset(...)` and populates `EmbeddedFontInfo`.

## What to add

Introduce a `FontSubsetResult` record (internal):

```csharp
internal sealed record FontSubsetResult(
    ReadOnlyMemory<byte> SubsetBytes,
    IReadOnlyDictionary<ushort, ushort> OldToNewGid,
    IReadOnlyList<ushort> SortedGids);
```

Change `TrueTypeFontSubsetter.BuildSubsetFont` (or the public surface called by FontPipeline) to return `FontSubsetResult` instead of `ReadOnlyMemory<byte>`.

Add `OldToNewGid` and `SortedGids` to `EmbeddedFontInfo` (or store the full `FontSubsetResult` there). Keep `SubsetBytes` as the primary property — do not break existing consumers.

## Windows build note

Do NOT use `-m:1 -nodereuse:false` on this machine (MSB3492 cache-lock with MSBuild SDK 10.0.201). Use plain `dotnet build` / `dotnet test`.
