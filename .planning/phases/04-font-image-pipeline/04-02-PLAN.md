2. Create `src/Muonroi.Pdf/Internal/Font/EmbeddedFontInfo.cs`:
   - Namespace: `Muonroi.Pdf.Internal.Font`
   - `internal sealed record EmbeddedFontInfo(string Family, FontWeight Weight, FontStyle Style, ReadOnlyMemory<byte> SubsetBytes, IReadOnlySet<int> UsedCodepoints)`
   - `FontWeight` and `FontStyle` come from `Muonroi.Pdf.Abstractions` (already in scope via project reference)
   - `UsedCodepoints` stores Unicode codepoint integers (not GID values) — TrueTypeFontSubsetter resolves codepoints to GIDs internally via cmap table

3. Create `src/Muonroi.Pdf/Internal/Font/SixLaborsTextMetrics.cs`:
   - Namespace: `Muonroi.Pdf.Internal.Font`
   - `internal sealed class SixLaborsTextMetrics : ITextMetrics`
   - Constructor: `SixLaborsTextMetrics(FontCollection fontCollection)`; store in `private readonly FontCollection _collection`
   - `GetCharWidth(char c, string fontFamily, float fontSize, bool bold, bool italic)`:
     - Build `SLFontStyle style = bold && italic ? SLFontStyle.BoldItalic : bold ? SLFontStyle.Bold : italic ? SLFontStyle.Italic : SLFontStyle.Regular`
     - Use alias `using SLFontStyle = SixLabors.Fonts.FontStyle;` to disambiguate from `Muonroi.Pdf.Abstractions.FontStyle`
     - If `!_collection.TryGet(fontFamily, out FontFamily family)` → return `fontSize * 0.6f` (fallback estimate matching EstimatedTextMetrics)
     - `Font font = family.CreateFont(fontSize, style)`
     - `TextOptions opts = new TextOptions(font)`
     - Return `TextMeasurer.MeasureAdvance(c.ToString(), opts).Width`
   - `GetLineHeight(string fontFamily, float fontSize)`:
     - If TryGet fails → return `fontSize * 1.2f`
     - `if (!family.TryGetMetrics(SLFontStyle.Regular, out FontMetrics? m) || m == null) return fontSize * 1.2f;`
     - Return `(float)m.HorizontalMetrics.LineHeight * fontSize / m.UnitsPerEm`
   - `GetAscender(string fontFamily, float fontSize)`:
     - If TryGet or TryGetMetrics fails → return `fontSize * 0.8f`
     - Return `(float)m.HorizontalMetrics.Ascender * fontSize / m.UnitsPerEm`
   - `GetDescender(string fontFamily, float fontSize)`:
     - If TryGet or TryGetMetrics fails → return `fontSize * 0.2f`
     - Return `Math.Abs((float)m.HorizontalMetrics.Descender * fontSize / m.UnitsPerEm)` — Descender is negative in design units; return positive value as depth below baseline
   - Add private helper `private bool TryGetFamily(string fontFamily, out FontFamily family)` that calls `_collection.TryGet(fontFamily, out family)` for reuse
  </action>

<task type="auto">

  <action>
Create `src/Muonroi.Pdf/Internal/Font/GlyphCollector.cs`:
- Namespace: `Muonroi.Pdf.Internal.Font`
- `internal sealed class GlyphCollector`
- Method: `internal IReadOnlyDictionary<string, IReadOnlySet<int>> Collect(PositionedPageList pageList, FontCollection fontCollection)`

Implementation:
1. Create `Dictionary<string, HashSet<int>> result` — key is font family name, value is set of Unicode codepoints (as int)
2. Iterate `foreach (PositionedPage page in pageList.Pages)`
3. Within each page, iterate its elements — check the exact property name on `PositionedPage` (likely `Elements` or `Items`; read the class if uncertain)
4. For each element where `element.Source is InlineBox inlineBox`:
   - Skip if `string.IsNullOrEmpty(inlineBox.Text)` or `string.IsNullOrEmpty(inlineBox.FontFamily)`
   - Ensure `result` has an entry for `inlineBox.FontFamily`
   - Build `SixLabors.Fonts.FontStyle sfStyle = inlineBox.Bold && inlineBox.Italic ? SixLabors.Fonts.FontStyle.BoldItalic : ...` (same mapping as SixLaborsTextMetrics)
   - If `fontCollection.TryGet(inlineBox.FontFamily, out FontFamily ff)`:
     - `Font font = ff.CreateFont(inlineBox.FontSize > 0 ? inlineBox.FontSize : 12f, sfStyle)`
     - For each `char ch` in `inlineBox.Text`:
       - Skip surrogate characters: `if (char.IsSurrogate(ch)) continue;`
       - If `font.TryGetGlyphs(new CodePoint(ch), out _)` returns true — the font has a glyph for this codepoint
       - `result[inlineBox.FontFamily].Add((int)ch)`
5. Return `result.ToDictionary(kvp => kvp.Key, kvp => (IReadOnlySet<int>)kvp.Value)` as `IReadOnlyDictionary<string, IReadOnlySet<int>>`

Note: We collect Unicode codepoints (not internal GID values) because SixLabors.Fonts CMap API is internal. `TrueTypeFontSubsetter` reads the font's cmap table directly to translate codepoints → GIDs.

Namespace aliases needed: `using SixLabors.Fonts;` for `FontCollection`, `FontFamily`, `Font`, `CodePoint`.
  </action>
