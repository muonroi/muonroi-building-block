Extend `AngleSharpStyledDocument` to implement `IReadOnlyList<FontFaceDeclaration> FontFaces`:

1. Add a private field `private readonly IReadOnlyList<FontFaceDeclaration> _fontFaces;` initialized in the constructor.

2. In the constructor, after the existing initialization, call a new private static method `ExtractFontFaces(document)` that returns `List<FontFaceDeclaration>`:
   - Iterate `document.StyleSheets.OfType<ICssStyleSheet>()` (same pattern as `AngleSharpPageRule.TryExtract`)
   - For each sheet, iterate `sheet.Rules` from `i=0` to `rules.Length-1`
   - Cast each rule with `rules[i] is ICssFontFaceRule fontFaceRule`
   - Extract and parse:
     - `string family = fontFaceRule.Family.Trim('\'', '"')` — strip CSS quotes
     - `FontWeight weight = ParseFontWeight(fontFaceRule.Weight)` — "bold"→Bold(700), "normal"→Normal(400), numeric string→int→cast to FontWeight enum (default Normal if unknown)
     - `FontStyle style = ParseFontStyle(fontFaceRule.Style)` — "italic"→Italic, "oblique"→Oblique, else→Normal
   - Add `new FontFaceDeclaration(family, weight, style)` to the list
   - After iterating: deduplicate using `Distinct().ToList()` (record equality used)
   - Return as `List<FontFaceDeclaration>`

3. Implement `ParseFontWeight(string? weight)` as a private static method:
   - If null or "normal" → `FontWeight.Normal`
   - If "bold" → `FontWeight.Bold`
   - If int.TryParse succeeds → cast to `FontWeight` (if value maps to a known enum member), else `FontWeight.Normal`
   - Any other string → `FontWeight.Normal`

4. Implement `ParseFontStyle(string? style)` as a private static method:
   - "italic" → `FontStyle.Italic`
   - "oblique" → `FontStyle.Oblique`
   - else → `FontStyle.Normal`

5. Add `public IReadOnlyList<FontFaceDeclaration> FontFaces => _fontFaces;` to the public surface.

Required using: `AngleSharp.Css.Dom` (for `ICssFontFaceRule`, `ICssStyleSheet`, `ICssRuleList`) — check if already imported in GlobalUsings.cs of Governance project; add if missing.
