  <action>
Create `src/Muonroi.Pdf/Internal/Font/TrueTypeFontSubsetter.cs`:
- Namespace: `Muonroi.Pdf.Internal.Font`
- `internal sealed class TrueTypeFontSubsetter`
- Method: `internal ReadOnlyMemory<byte> Subset(ReadOnlyMemory<byte> fontBytes, IReadOnlySet<int> usedCodepoints)`

**Step 1 — Detect TTF vs CFF-OTF:**
- Read `uint sfntVersion = BinaryPrimitives.ReadUInt32BigEndian(fontBytes.Span)`
- If `sfntVersion == 0x4F54544F` (CFF-OTF 'OTTO') → return `fontBytes` unchanged (no subsetting for CFF)
- If `sfntVersion != 0x00010000` → throw `PdfException("FONT-FORMAT", $"Unrecognized font format (sfntVersion: 0x{sfntVersion:X8})")`

**Step 2 — Parse Table Directory:**
- `ushort numTables = BinaryPrimitives.ReadUInt16BigEndian(fontBytes.Span.Slice(4, 2))`
- Sanity check: `if (numTables < 1 || numTables > 100) throw PdfException("FONT-FORMAT", ...)`
- Parse each `TableRecord` at `offset 12 + i * 16`:
  - `string tag = Encoding.ASCII.GetString(fontBytes.Span.Slice(12 + i*16, 4))`
  - `uint tableOffset = BinaryPrimitives.ReadUInt32BigEndian(fontBytes.Span.Slice(12 + i*16 + 8, 4))`
  - `uint tableLength = BinaryPrimitives.ReadUInt32BigEndian(fontBytes.Span.Slice(12 + i*16 + 12, 4))`
  - Bounds check: `if (tableOffset + tableLength > fontBytes.Length) throw PdfException("FONT-FORMAT", "Table extends beyond font bounds")`
  - Store in `Dictionary<string, (uint offset, uint length)> tables`

**Step 3 — Read cmap table to map codepoints → GIDs:**
- Find cmap table in `tables`
- Read cmap header at `tables["cmap"].offset`
- Find Format 4 subtable (BMP codepoints — sufficient for Vietnamese + Latin)
- Parse Format 4: `segCountX2`, endCode[], startCode[], idDelta[], idRangeOffset[], glyphIdArray[]
- For each `int codepoint` in `usedCodepoints`:
  - Find segment where `startCode[i] <= codepoint <= endCode[i]`
  - If `idRangeOffset[i] == 0`: GID = `(codepoint + idDelta[i]) & 0xFFFF`
  - Else: GID from glyphIdArray offset calculation per spec
  - Skip unmapped codepoints (GID would be 0 = .notdef)
- Accumulate `HashSet<ushort> usedGids`

**Step 4 — Composite glyph closure:**
Add `.notdef` (GID 0) to `usedGids`. Then:
```
Queue<ushort> pending = new(usedGids)
while pending has items:
    gid = pending.Dequeue()
    if IsComposite(glyf table, loca table, gid):
        foreach componentGid in GetComponentGids(glyf, loca, gid):
            if usedGids.Add(componentGid):
                pending.Enqueue(componentGid)
```
Use long loca format (indexToLocFormat from head table at offset 50).

**Step 5 — Build subset font:**
Create sorted array `ushort[] sortedSubsetGids` from `usedGids`. Build GID remapping: `oldGid → newGid` where newGid = index in sorted array.

Mandatory tables to include (copy these from the source font, rebuilding where needed):
- `head`: copy, set `checksumAdjustment = 0` initially, set `indexToLocFormat = 1` (long format)
- `hhea`: copy
- `maxp`: copy, update `numGlyphs` to `sortedSubsetGids.Length` (at offset 4, uint16)
- `OS/2`: copy
- `name`: copy
- `post`: copy
- `hmtx`: rebuild — include only entries for retained GIDs (each entry = 4 bytes: advanceWidth uint16 + lsb int16)
- `glyf`: rebuild — concatenate glyph data for sorted retained GIDs; update component glyphIndex values to new GID space
- `loca`: rebuild — long format; one uint32 offset per glyph + trailing entry
- `cmap`: rebuild — Format 4 mapping from original codepoints to new GID space (for codepoints in usedCodepoints that mapped successfully)
- `kern`, `cvt `, `fpgm`, `prep`: copy if present in source

Write new font binary:
1. Table directory header: sfntVersion=0x00010000, numTables, searchRange, entrySelector, rangeShift
2. Table records (16 bytes each, sorted alphabetically by tag)
3. Table data (4-byte aligned, padded)
4. Calculate each table checksum (sum of uint32 words, last word padded with zeros)
5. Whole-file checksum; `head.checksumAdjustment = 0xB1B0AFBA - wholeFileChecksum`
6. Write final `checksumAdjustment` into the head table bytes

Return `new ReadOnlyMemory<byte>(outputBytes)`.

For methods `IsComposite` and `GetComponentGids`: implement as private static methods that read directly from the `fontBytes.Span` using the loca/glyf table offsets.

Create `src/Muonroi.Pdf/Internal/Font/FontPipeline.cs`:
- Namespace: `Muonroi.Pdf.Internal.Font`
- `internal sealed class FontPipeline`
- No constructor dependencies (resolver is a method parameter — stateless class)

Method:
```
internal async Task<(SixLaborsTextMetrics TextMetrics, IReadOnlyDictionary<string, ReadOnlyMemory<byte>> FontBytesMap)> ResolveAsync(
    IStyledDocument doc,
    IFontResolver resolver,
    PdfConfigs.PdfLimits limits,
    CancellationToken ct)
```

Implementation:
1. Read font faces: `IReadOnlyList<FontFaceDeclaration> fontFaces = doc.FontFaces`

2. Validate count: `if (fontFaces.Count > PdfConfigs.PdfLimits.MaxFontFiles)` → throw `new PdfInputLimitException("FONT-MAX-FILES", "MaxFontFiles", fontFaces.Count, PdfConfigs.PdfLimits.MaxFontFiles)`. This check runs BEFORE any `ResolveAsync` call.

3. Build `FontCollection collection = new FontCollection()`

4. Build `Dictionary<string, ReadOnlyMemory<byte>> fontBytesMap` — keyed by family name

5. For each `FontFaceDeclaration decl` in `fontFaces`:
   - `ct.ThrowIfCancellationRequested()`
   - `FontRequest request = new(decl.Family, decl.Weight, decl.Style)`
   - `ReadOnlyMemory<byte>? bytes = await resolver.ResolveAsync(request, ct).ConfigureAwait(false)`
   - If `bytes == null`:
     - `System.Diagnostics.Debug.WriteLine($"[FontPipeline] Font not resolved: {decl.Family}")`
     - `continue` (skip; layout will use fallback estimate for this family)
   - `collection.Add(new MemoryStream(bytes.Value.ToArray()))` — ToArray() required because MemoryStream wraps array and ReadOnlyMemory segment may not start at offset 0
   - `fontBytesMap[decl.Family] = bytes.Value` — save for TrueTypeFontSubsetter later

6. Return `(new SixLaborsTextMetrics(collection), fontBytesMap)`

No logging via IMLog — use `System.Diagnostics.Debug.WriteLine` for skipped fonts (same pattern as ImagePipeline). IMLog wiring is Phase 6.

## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-04-04 | Tampering | CFF-OTF bytes incorrectly processed as TTF | mitigate | sfntVersion `0x4F54544F` ('OTTO') detected first; full bytes returned unchanged |
</threat_model>
