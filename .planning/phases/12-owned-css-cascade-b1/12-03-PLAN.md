  <behavior>
    - OwnedStyledNode over a text node: IsText true, IsElement false, LocalName "#text", Style is an
      empty OwnedComputedStyle (text nodes have no cascade).
    - OwnedStyledNode over an element with a matched `.a { color: red }` rule: Style.GetValue("color") == "red".
    - A child element with no own color whose parent resolves color: red: child Style.GetValue("color") == "red"
      (parent's resolved map threaded in).
    - Children returns OwnedStyledNode wrappers for child elements and text nodes only (comments skipped),
      preserving order — same filtering as the old AngleSharpStyledNode.
    - Style is computed once and cached: two reads of .Style return the same resolved values (resolver
      invoked at most once per node).
  </behavior>
  <action>
    Create `internal sealed class OwnedStyledNode : IStyledNode`. Constructor takes the `INode`, the
    shared `CascadeResolver`, and the parent's resolved map (`IReadOnlyDictionary&lt;string,string&gt;?`, null
    for the root). Mirror `AngleSharpStyledNode` for `LocalName`, `TextContent`, `GetAttribute`,
    `IsElement`, `IsText`, and the `Children` filtering (elements + text nodes), but each child
    OwnedStyledNode receives THIS node's resolved map as its parent map (resolve lazily; see caching note).

    `Style`: if the node is an `IElement`, lazily call `resolver.Resolve(element, parentResolved)`, wrap
    the result in `OwnedComputedStyle`, and cache both the `IComputedStyle` and the raw map (the raw map
    is what children thread as their parent map). For text nodes, return an empty `OwnedComputedStyle`.
    Cache with a nullable backing field so the resolver runs at most once per node.

    Because children need this node's resolved MAP (not just IComputedStyle), expose the resolved map
    internally (e.g. an internal property or pass it when constructing children). Ensure inheritance flows
    root→leaf: resolving a child triggers resolving its ancestors' maps on demand (lazy chain) OR resolve
    eagerly top-down — pick whichever keeps a single resolve per node; document the choice.

    Do NOT reference `IWindow`, `GetComputedStyle`, or `ComputeCurrentStyle`. Do NOT modify Abstractions.
  </action>
