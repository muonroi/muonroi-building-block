## Existing BoxNode shape (confirmed by RESEARCH.md code read)

`BoxNode` is the abstract base for all box types. It currently has:
- `Source` (IStyledNode?)
- `Position` / `Margin` / `Padding` / `Border` geometry
- Sub-types: `BlockBox`, `InlineBox`, `TableBox`, `TableCellBox`, `ImageBox`, `RootBox`

Add to `BoxNode`:
```csharp
public string? TextAlign { get; set; }
```
`text-align` is an inherited CSS property, so it lives on the base `BoxNode` where the layout engine can read it from any containing block.

## Existing InlineBox shape (confirmed by RESEARCH.md code read)

`InlineBox` inherits `BoxNode` and currently has:
- `Text` (string?)
- `FontFamily` (string?)
- `FontSize` (float)
- `Color` (string?)
- `IsBold`, `IsItalic` (bool)

Add to `InlineBox`:
```csharp
public float LineHeightFactor { get; set; } = 1.0f;
public string? TextDecoration { get; set; }   // "underline" | "line-through" | "none" | null
public string? LinkHref { get; set; }          // non-null if inside an <a> element
```
