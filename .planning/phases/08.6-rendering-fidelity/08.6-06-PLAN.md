## FontRejectionTests — synthetic font byte construction

To test OTF-CFF rejection without a real .otf file, construct a minimal 4-byte byte array with the magic sfntVersion:
```csharp
// OTF-CFF header: sfntVersion = 0x4F54544F
byte[] otfCffBytes = [(byte)0x4F, (byte)0x54, (byte)0x54, (byte)0x4F, ...(pad to minimum parse size)];
```
The subsetter reads bytes [0..3] for sfntVersion — it should throw before needing more. Use a 4-byte array padded with zeros if needed to avoid any index-out-of-bounds before the sfntVersion check.

For WOFF: sfntVersion = `[0x77, 0x4F, 0x46, 0x46]`
For WOFF2: sfntVersion = `[0x77, 0x4F, 0x46, 0x32]`

Call `TrueTypeFontSubsetter.Subset(fontBytes, usedGids)` directly (it is `internal sealed` — tests should be in the same assembly or use InternalsVisibleTo).

## ImageRejectionTests — minimal PNG construction

A minimal PNG that triggers each variant gate only needs a valid 33-byte PNG header + IHDR chunk:
```
PNG signature: 8 bytes [0x89 0x50 0x4E 0x47 0x0D 0x0A 0x1A 0x0A]
IHDR chunk length: 4 bytes [0x00 0x00 0x00 0x0D]
IHDR chunk type: 4 bytes [0x49 0x48 0x44 0x52]
Width: 4 bytes [0x00 0x00 0x00 0x01]   (1 pixel)
Height: 4 bytes [0x00 0x00 0x00 0x01]  (1 pixel)
bit_depth: 1 byte [0x08]               (8-bit)
color_type: 1 byte [0x06]              (RGBA → set to 0x03, 0x00, 0x04, 0x06, or 0x10 for each test)
compression, filter, interlace: 3 bytes [0x00 0x00 0x00]
CRC: 4 bytes [can be 0x00 0x00 0x00 0x00 — PureImageDecoder.DecodePng reads IHDR before CRC validation]
```
Offsets 24 and 25 in the full byte array are the bit_depth and color_type bytes. Construct targeted arrays for each color_type test.

Call `PureImageDecoder.DecodePng(pngBytes)` directly.
