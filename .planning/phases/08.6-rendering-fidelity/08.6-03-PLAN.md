## BoxTreeBuilder changes (per RESEARCH.md Task 2)

### ResolveCssProperties — three new reads

For `text-align`: `IComputedStyle.GetValue("text-align")` returns "left" | "right" | "center" | "justify" | null. Store on `box.TextAlign`. Default null = left (no offset).

For `line-height`: `IComputedStyle.GetValue("line-height")` returns a string. Parse rules:
- `"normal"` or null → `box.LineHeightFactor = 1.0f` (no-op)
- Unitless (e.g., `"1.5"`) → `box.LineHeightFactor = float.Parse(value)`
- px-length (e.g., `"24px"`) → `box.LineHeightFactor = parsedPx / box.FontSize` (where FontSize is the resolved font size in pt; 1px ≈ 0.75pt; use 24 × 0.75 / fontSize)
- percentage (e.g., `"150%"`) → `box.LineHeightFactor = parsedPercent / 100f`
Store on the InlineBox (not BoxNode).

For `text-decoration`: `IComputedStyle.GetValue("text-decoration")` returns "underline" | "line-through" | "none" | null. Store on `InlineBox.TextDecoration`.

### CreateBox — HTML5 element dispatch

Read `node.LocalName` before the existing default. Add these cases:
- `"br"` → `return new LineBreakBox { Source = node };`
- `"hr"` → create `HrBox`, read `border-top-width` (or `border-width`) for Thickness; read `color` for Color; return HrBox.
- `"a"` → create `InlineBox` as before (for text content), set `LinkHref = node.GetAttribute("href")`. Then apply the href security filter (see below). Children inherit LinkHref via the FlattenInline traversal (pass href down when flattening an `<a>` subtree).

### javascript: href filter

After reading `href`, validate the scheme. Only `http`, `https`, and `mailto` are permitted. For any other scheme (including `javascript:`, `file:`, `data:`, empty anchor `#`-only):
- Set `inlineBox.LinkHref = null`
- Record a policy violation via the existing `PolicyViolation` mechanism: `AddViolation(new PolicyViolation("forbidden.link.scheme", $"href scheme '{scheme}' is not allowed. Only http, https, and mailto URIs become link annotations.", node.GetAttribute("href"), "Use an http or https URI."))`

Scheme extraction: `Uri.TryCreate(href, UriKind.Absolute, out var uri) ? uri.Scheme : ""`. If parse fails (relative URL), treat as `http`-relative and allow (LinkHref = href as-is, will be emitted as a relative URI action — valid PDF behavior).

### BuildNode — list marker generation

When processing an `<li>` element:
1. Determine list type by walking to the nearest ancestor `<ul>` or `<ol>`.
2. For `<ul>`: marker text = `"• "` (U+2022 + space).
3. For `<ol>`: maintain `int ordinalCounter` scoped to each `<ol>` pass; marker text = `$"{ordinalCounter}. "`.
4. Create a synthetic `InlineBox`: `new InlineBox { Text = markerText, FontFamily = liComputedStyle.FontFamily, FontSize = liComputedStyle.FontSize, Color = liComputedStyle.Color }`.
5. The `<li>` block must have a left indent. Read `padding-left` from `<li>` computed style; if not set, default to `40 × 0.75 = 30f` pt (40px → pt). Set `liBox.Padding.Left = resolvedPaddingLeft`.
6. The marker InlineBox is the first box in the `<li>`'s inline content sequence — prepend it before the regular `<li>` children when building the inline flow.

The synthetic marker InlineBox is created in BoxTreeBuilder (before FontPipeline) so GlyphCollector picks up U+2022.

## InlineLayoutEngine changes (per RESEARCH.md Task 3)

### LayoutContext.TextAlign

Add `public string? TextAlign { get; set; }` to `LayoutContext`. When `BlockLayoutEngine` dispatches inline layout for a block, set `context.TextAlign = blockBox.TextAlign`.

### CommitLine — totalLineWidth computation

Before the x-offset computation, sum the widths of all pending words and their inter-word spaces (minus the trailing space on the last word). Call this `totalLineWidth`.

### CommitLine — x-offset by alignment

```csharp
float availWidth = context.ContentWidth;  // or pageWidth - margins
float wordOffsetX = context.TextAlign switch {
    "right"   => availWidth - totalLineWidth,
    "center"  => (availWidth - totalLineWidth) / 2f,
    "justify" when !isLastLine && wordCount > 1
              => 0f, // x starts at left; gap bonus computed below
    _         => 0f  // left (default)
};
```

For justify: `float gapBonus = (availWidth - totalLineWidth) / (wordCount - 1)`. Each inter-word gap = `spaceWidth + gapBonus`. Apply to word x-positions during the positioning loop.

### CommitLine — isLastLine parameter

Add `bool isLastLine` parameter to `CommitLine`. The post-loop `CommitLine()` call (flushing the final line after all words are placed) passes `isLastLine = true`. Mid-loop `CommitLine()` calls (word-wrap break) pass `isLastLine = false`. Justify does NOT apply to the last line.

### CommitLine — line-height scaling

When computing `lineHeight` (the Y advance after the line), multiply by the dominant box's `LineHeightFactor`: `lineHeight *= dominantBox.LineHeightFactor`. "Dominant box" = the InlineBox with the largest font size on the line (already tracked to determine line baseline).

### LineBreakBox handling

In the word-iteration loop of `InlineLayoutEngine.Layout`, when a `LineBreakBox` is encountered in the flattened inline stream:
- Call `CommitLine(isLastLine: false)` immediately to flush whatever is pending.
- Do NOT add the `LineBreakBox` itself to the pending-words list.
- Continue the loop.

### Link rect collection

In `CommitLine`, after computing the final position `(x, y, width, height)` for each word:
```csharp
if (pendingBox.LinkHref != null)
{
    page.LinkAnnotations.Add(new LinkAnnotation(
        pendingBox.LinkHref, x, y, wordWidth, lineHeight, pageIndex));
}
```

## BlockLayoutEngine changes (per RESEARCH.md Task 4)

In `DispatchLayout`, add a case for `HrBox` before the existing default block dispatch:

```csharp
case HrBox hr:
    float hrHeight = hr.MarginTop + hr.Thickness + hr.MarginBottom;
    layoutY += hr.MarginTop;
    elements.Add(new PositionedElement {
        Source = hr,
        Position = new Rect(context.ContentLeft, layoutY, context.ContentWidth, hr.Thickness)
    });
    layoutY += hr.Thickness + hr.MarginBottom;
    break;
```
