|----------|-------------|
| admin caller → renew endpoint | Issuance-class operation; must be authz-gated (license-generate policy). |
| renew → RSA signing | Re-signing must use the existing private-key machinery, never a forked/weakened signer. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-10 | Elevation of Privilege | renew endpoint | mitigate | RequireAuthorization("license-generate") — same gate as issuance; AdminApiKeyMiddleware already in pipeline |
| T-17-11 | Tampering | re-sign on renew | mitigate | reuse LicenseSigningService.SignAsync + BuildLicenseSigningData; no new/forked crypto (D-04) |
| T-17-12 | Spoofing | renewing a revoked license | mitigate | RenewAsync rejects IsRevoked records — covered by test |
