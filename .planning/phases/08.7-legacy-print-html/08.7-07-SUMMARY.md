# Phase 08.7 Plan 07: Background + Text/Whitespace Hardening Summary

## What Was Built

### Background rendering (OwnedPdfWriter)
- `BoxNode.BackgroundColor` / `BackgroundImageSrc` properties
- BoxTreeBuilder reads `background-color` (skips "transparent"/"initial") and extracts data URI from `background-image: url(...)`
- ImagePipeline extended: CollectImageSrcs now also yields background-image data URIs from CSS
- OwnedPdfWriter: for each PositionedElement, draws background-color rect then background-image XObject before text/image content

### Inline layout hardening
- `InlineBox.TextTransform` ("uppercase"|null) + `InlineBox.WhiteSpace` ("pre-wrap"|"pre-line"|"nowrap"|null)
- BoxTreeBuilder reads `text-transform` and `white-space` in InlineBox branch
- BoxTreeBuilder.CreateBox: `<nobr>` element → `InlineBox { WhiteSpace="nowrap" }`
- BoxTreeBuilder.ParseLength: `rem` units → `value * 16f * PxToPt`
- InlineLayoutEngine: text-transform applied before GetCharWidth measurement
- InlineLayoutEngine: white-space:nowrap = single unbreakable token
- InlineLayoutEngine: white-space:pre-line/pre-wrap splits on '\n', each '\n' forces CommitLine
