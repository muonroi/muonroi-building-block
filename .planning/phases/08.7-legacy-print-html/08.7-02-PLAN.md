  In Pass 2 (per-element computed style), the ONLY difference from DefaultStrictPolicy:
    - Remove the "floatVal is 'left' or 'right'" violation.

      "background-image" contains "gradient", add violation "forbidden.background.gradient".

  Id = "legacy-print-v1". Limits = PdfPolicyLimits.Strict (same as DefaultStrictPolicy).

  Do NOT add a public constructor with parameters — parameterless default only.
  Do NOT reference any layout-engine internals — this is Governance layer only.
