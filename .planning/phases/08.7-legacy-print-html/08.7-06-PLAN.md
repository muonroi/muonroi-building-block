<objective>
Implement position:absolute — CSS 2.1 §9.6 pragmatic deferred-pass approach.

Purpose: 8 of 17 corpus templates use position:absolute to overlay barcodes and logo images
on a position:relative containing table. Without this, the barcode divs fall into normal flow
and break the page layout.

Scope: corpus pattern is always explicit top/left/right (px or %) with explicit width/height
on the absolutely positioned element. No "auto" resolution needed. Containing block is always
an explicit position:relative element with known dimensions.

Note: Plan 05 (float) and Plan 06 (abs-pos) both modify BoxNode.cs, LayoutContext.cs,
BoxTreeBuilder.cs, and BlockLayoutEngine.cs. They are assigned the SAME wave (Wave 3)
specifically because they touch the SAME files — they MUST run sequentially, not in parallel.
Wave 3 = Plans 05 and 06 are sequential. The orchestrator must run 05 first, then 06.
</objective>
