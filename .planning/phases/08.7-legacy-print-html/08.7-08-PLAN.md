  After running, write CAPABILITY-CONTRACT.md at .planning/phases/08.7-legacy-print-html/:

  CAPABILITY-CONTRACT.md sections:
  1. Profile Name: Legacy Print-HTML Profile v1
  2. Policy: LegacyPrintPolicy (Id: "legacy-print-v1") — reference for caller registration
  3. Supported Layout Primitives:
     - Tables: colspan, rowspan, border-collapse:collapse, vertical-align in cells
     - Float layout: float:left/right + clear:both (two-column pattern; no inline text wrapping)
     - Positioned layout: position:absolute (px/%) in position:relative containing block
     - Inline: text-transform:uppercase, white-space:pre-line/pre-wrap, nobr, rem units
     - Block: background-color, background-image (data-URI), borders
     - Text: font-family mapped to Liberation Serif/Sans/Mono via bundled fallback
  4. Fail-Loud Rejections: flexbox, grid, position:fixed/sticky, @keyframes, CSS variables,
     transform (geometric), box-shadow, border-radius, calc(), nested tables,
     RGBA/palette/grayscale PNG, gradient backgrounds, external URL resources
  5. Template Format Contract (for Phase 9 Designer seam):
     - Input: UTF-8 HTML string (post-fill; no {{...}} placeholders)
     - Page size: declared in @page { size: A4 landscape / A5 portrait / ... }
     - Images: base64 data URIs only (8-bit RGB PNG or JPEG); no external URLs
     - Fonts: standard family names (Times New Roman, Arial, Helvetica, Courier New, monospace)
       map to bundled Liberation fonts; caller may override via IFontResolver + @font-face
     - Max table nesting depth: 1 (no nested tables)
  6. Layout IR Seam (Phase 9 note):
     - The engine produces a PositionedPageList (list of PositionedPage, each with PositionedElements)
     - Each PositionedElement has a Source (BoxNode) and a Position (Rect on the page)
     - The Phase 9 Designer emits HTML conforming to this Profile; the CSS-decoupled layout IR
       (PositionedPageList) is the seam between the engine and any future visual renderer/designer
     - Key constraint: the Designer must emit only Profile v1 CSS features to guarantee rendering
  7. Validated Templates: [list from test run]
  8. Known Gaps / Out-of-Scope: full CSS 2.1 §17.6.2 border-conflict resolution;
     line-box shortening for inline text wrapping around floats; nested tables; RGBA images
  </action>
