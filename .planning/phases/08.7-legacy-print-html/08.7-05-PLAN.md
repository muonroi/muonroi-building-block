<objective>
Implement float:left/right + clear:both — CSS 2.1 §9.5 pragmatic two-column model.

Purpose: 9 of 17 corpus templates use float layout for headers (logo-left, barcode-right).
Without float support, these sections collapse to stacked vertical blocks, producing completely
wrong output. This is SC-1 in the Phase 8.7 roadmap.

Scope is pragmatic: the corpus uses floats only as a two-column side-by-side pattern (no text
wrapping around inline floats). The implementation is a simplified BFC float accumulator — not
the full CSS 2.1 line-box shortening algorithm.

Output: BoxNode.FloatValue/ClearValue, LayoutContext float fields, BlockLayoutEngine float
dispatch + clear handling, BFC scoping, golden tests.
</objective>

    if (child.FloatValue != null && child is BlockBox floatBlock)

        float floatHeight = Layout(floatBlock, ctx, output, pageIndex);
        float floatY = ctx.CurrentY;

        if (child.FloatValue == "left")
        {
            float floatX = ctx.PageMarginLeftPt + floatBlock.MarginLeft;
            output.Add(new PositionedElement
