<objective>
Bundle Liberation Fonts as embedded assembly resources and wire a family-name fallback mapping
so templates that declare "Times New Roman", "Arial", "Helvetica", or "monospace" without
@font-face declarations get a valid embedded font instead of crashing with
PdfFormatException("GID map missing for 'serif'").

Purpose: HSLA_E (and 8 other _E templates) use "Times New Roman" with no @font-face. Production
TCIS wraps them in @font-face before rendering, but the baseline harness and any consumer
calling the engine directly must not crash. This is the third Wave 0 unblocking fix.

Output: BundledFonts.cs (mapping table + resource loader) + FontPipeline changes + updated
FontPipelineTests.
</objective>
