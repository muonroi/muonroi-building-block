## Page size mapping

- A4 → 595.28 × 841.89

- Letter → 612.0 × 792.0
- Legal → 612.0 × 1008.0

`PdfRenderOptions.Orientation`: if Landscape, swap Width and Height.

`Muonroi.Pdf.Abstractions.FontWeight` vs `SixLabors.Fonts.FontStyle`: Use weight ≥ 600 as bold threshold.
`Muonroi.Pdf.Abstractions.FontStyle.Italic` or `Oblique` → `XFontStyle.Italic`.

## Determinism approach

PdfSharpCore writes a trailer `/ID [<hash1> <hash2>]`. The hashes are derived from document metadata. To achieve deterministic output:
1. Set all `doc.Info` string fields to empty strings (no title, no author, etc. — prevents metadata variation from affecting the hash)
2. Suppress timestamps: `doc.Info.CreationDate = new DateTime(2000, 1, 1, 0, 0, 0, DateTimeKind.Utc)` (a fixed sentinel date)
3. If `doc.Info.ModificationDate` property exists, set it to the same sentinel date
4. Verify in Plan 05-03 tests that rendering the same document twice produces identical bytes

If after step 1-3 the output is still non-deterministic (check by running the integration test twice and comparing), do a binary post-process: find and zero-out the 32-byte ID in the trailer before writing to the final stream. The PDF trailer `/ID` entry is near the end of the file in a predictable location — scan backward from EOF to find the `%% trailer` block, then replace the ID hex strings with zeros.

## PDF 1.7 enforcement

After `doc.Save(ms)`:
1. Read `ms.GetBuffer()` (or `ms.ToArray()`) 
2. Check if bytes 0-7 are `%PDF-1.` — if the version digit (byte 7) is not `7`, overwrite bytes 5-7 with `1.7` 
3. This normalizes any PdfSharpCore default version (typically `%PDF-1.3` or `%PDF-1.4`) to `%PDF-1.7`

## Security: never-write guarantee for SEC-02

The writer is constructive — it only calls APIs that produce text, images, and metadata. It never calls any PdfSharpCore API that writes `/JavaScript`, `/Launch`, `/OpenAction`, or `/EmbeddedFile`. This is architectural enforcement, not runtime checking. The security is in what the writer does NOT do.

Add a comment block at the top of `PdfSharpCoreWriter.cs`:
```
// Security invariants (SEC-02):
// This writer NEVER calls APIs that produce /JavaScript, /Launch, /OpenAction,
// or /EmbeddedFile dictionary entries. The absence of such calls IS the enforcement.
// Any future code path that would add such entries must be reviewed and blocked.
```

`WriteAsync(IPositionedPageList pages, PdfRenderOptions options, Stream destination, CancellationToken ct)`:
1. Cast: `if (pages is not PositionedPageList pageList) throw new InvalidOperationException("PdfSharpCoreWriter requires PositionedPageList from the Muonroi.Pdf engine");`
2. Under `lock(_fontResolverLock)`:
   a. Save previous resolver: `var previous = GlobalFontSettings.FontResolver;`
   b. Set new resolver: `GlobalFontSettings.FontResolver = new PdfSharpFontResolverAdapter(pageList.EmbeddedFonts);`
   c. `var ms = new MemoryStream(); RenderDocument(pageList, options, ms);`
   d. Restore: `GlobalFontSettings.FontResolver = previous;`
3. `byte[] pdfBytes = ms.ToArray();`
4. Apply PDF 1.7 version patch: if `pdfBytes.Length >= 8` and bytes 0-7 match `%PDF-1.x`, replace byte 7 with `(byte)'7'`
5. `await destination.WriteAsync(pdfBytes, ct);`
6. Return `pdfBytes.Length`

`RenderDocument(PositionedPageList pageList, PdfRenderOptions options, Stream ms)`:
- `PdfDocument doc = new PdfDocument();`
- Suppress non-determinism (SEC-03, SEC-04, DET-01/02/03):

  - `doc.Info.Author = string.Empty;`
  - `doc.Info.Subject = string.Empty;`
  - `doc.Info.Keywords = string.Empty;`
  - `doc.Info.Creator = string.Empty;`

- Get page size dimensions: `(double w, double h) = GetPageDimensions(options);`
- For each `PositionedPage page in pageList.Pages`: `RenderPage(doc, page, pageList.Images, w, h, ct);`
- `doc.Save(ms);` then `doc.Close();`

`GetPageDimensions(PdfRenderOptions options) → (double width, double height)` in points:
- A4: (595.28, 841.89); A5: (419.53, 595.28); Letter: (612.0, 792.0); Legal: (612.0, 1008.0)
- If landscape orientation: swap width and height

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PositionedPageList → PdfSharpCoreWriter | Internal-only boundary; cast validates source is trusted engine output |
| Images dict → XImage | Raw bytes from IResourceResolver flow into XImage; already validated by ImagePipeline (MaxImagePixels, format headers) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Tampering | GlobalFontSettings.FontResolver (global state) | mitigate | `_fontResolverLock` static lock ensures one render at a time controls the resolver; previous resolver restored in all code paths |
| T-05-05 | Information Disclosure | PdfSharpCoreWriter timestamp suppression | mitigate | All doc.Info string fields set to empty; CreationDate set to fixed sentinel — prevents metadata from leaking render-time information |
| T-05-06 | Elevation of Privilege | InlineBox.Color injection | accept | CSS color values originate from the policy-gated cascade engine; inline style injection must have passed the policy gate before reaching the writer |
