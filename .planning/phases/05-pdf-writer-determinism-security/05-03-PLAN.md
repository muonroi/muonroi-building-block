## Checking PDF header

```csharp

string header = Encoding.ASCII.GetString(pdfBytes, 0, 8);
header.Should().StartWith("%PDF-1.7");
```

## Checking no timestamp

Scan the raw bytes for the literal string `CreationDate` or `ModDate`:
```csharp
string pdfText = Encoding.Latin1.GetString(pdfBytes);
pdfText.Should().NotContain("/CreationDate");
pdfText.Should().NotContain("/ModDate");
```

Note: if the sentinel date (2000-01-01T00:00:00Z) appears as `/CreationDate (D:20000101000000Z)`, that's acceptable — but ideally CreationDate is not emitted at all. If it IS emitted with the sentinel, update the test to allow the sentinel date but assert no CURRENT timestamp.

## Determinism test pattern

```csharp
// First render
var ms1 = new MemoryStream();
await writer.WriteAsync(pageList, options, ms1, ct);

// Second render (same input, same process)
var ms2 = new MemoryStream();
await writer.WriteAsync(pageList, options, ms2, ct);

ms1.ToArray().Should().BeEquivalentTo(ms2.ToArray(), "renders of the same input must be byte-identical");
```

If this fails: the binary post-processing step in PdfSharpCoreWriter (normalizing the /ID field) may not be implemented yet. The test failing is the signal to add the post-processing to the writer.


## Script element policy test pattern

Requires an AngleSharp parsed document with a `<script>` tag. Use the existing Governance parsing infrastructure or inject a mock `IDocument`. The simplest approach: use `AngleSharpHtmlParser` to parse HTML containing a script tag, then cascade with `AngleSharpCascadeEngine`, then call `DefaultStrictPolicy.ValidateAsync`.

```csharp
// Use existing Governance parsing classes (accessible via InternalsVisibleTo or as public classes)
var parser = new AngleSharpHtmlParser();
var parsed = await parser.ParseAsync("<html><body><script>alert(1)</script></body></html>",
    new PdfRenderOptions(), PdfConfigs.PdfLimits, CancellationToken.None);
var cascade = new AngleSharpCascadeEngine();
var styled = await cascade.ApplyAsync(parsed, CancellationToken.None);
var policy = new DefaultStrictPolicy();
var result = await policy.ValidateAsync(styled as IPdfDocumentContext ?? (IPdfDocumentContext)styled, CancellationToken.None);
result.IsValid.Should().BeFalse();
result.Violations.Should().Contain(v => v.RuleId == "forbidden.script-element");
```

Note: Check how `AngleSharpStyledDocument` implements `IPdfDocumentContext` — look at the existing test files for the pattern used in governance tests.
