Create `ThrowingResourceResolver` in `Muonroi.Pdf.Internal.Security` namespace (file in `src/Muonroi.Pdf/Internal/Security/`):
- `internal sealed class ThrowingResourceResolver : IResourceResolver`
- `ResolveAsync(Uri uri, string? contentTypeHint, CancellationToken ct)`:
  - Check `uri.Scheme` (case-insensitive):
    - If `"file"` → throw `new PdfSecurityException("SEC-06", $"file:// URI scheme is not permitted: {uri}")`
    - If `"javascript"` → throw `new PdfSecurityException("SEC-06", $"javascript: URI scheme is not permitted: {uri}")`
  - For all other schemes (http, https, ftp, data, etc.) → return `null` (resource not resolved; engine logs debug and uses 0×0 placeholder)
  - This is the SAFE default: external resources are not fetched; callers that need resolution supply their own `IResourceResolver` via `PdfRenderOptions.ResourceResolver`
  - NOTE: http:// and https:// return null (not throw) — they are simply unavailable by default, not a security violation per SEC-06 which specifically targets file://
