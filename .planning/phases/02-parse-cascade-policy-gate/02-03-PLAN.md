## Critical Implementation Notes

1. **MaxHtmlBytes check is pre-parse**: Check `html.Length * 2 > PdfConfigs.PdfLimits.MaxHtmlBytes` BEFORE calling `BrowsingContext.OpenAsync`. Use `* 2` as a conservative UTF-16 byte estimate. This prevents allocating a large DOM before detecting the violation.

2. **No `.WithDefaultLoader()`**: Omitting this prevents AngleSharp from making outbound HTTP requests for `<link>` or `@import` URLs. The policy gate (Plan 02-05) will catch external `@import` as a policy violation.

3. **Iterative depth walk**: The DOM depth check must use an iterative approach (explicit `Stack<T>`) rather than recursion. Deep documents with nesting close to MaxDomDepth=256 would cause `StackOverflowException` with recursive DFS. See code pattern below.

4. **`AngleSharpParsedDocument` visibility**: Must be `internal sealed` — never `public`. Only `AngleSharpHtmlParser` (same assembly) constructs it; only `AngleSharpCascadeEngine` (same assembly, Plan 02-04) reads from it via internal cast.

5. **Rule ID strings** (exact, for telemetry consistency):
   - `"limit.max-html-bytes"` — MaxHtmlBytes exceeded
   - `"limit.max-dom-depth"` — MaxDomDepth exceeded
   - `"limit.max-element-count"` — MaxElementCount exceeded

## Iterative Depth Walk Pattern

```csharp
// [ASSUMED] Standard DOM traversal — iterative to avoid stack overflow
internal static int ComputeMaxDepth(IDocument document)
{
    var root = document.DocumentElement;
    if (root is null) return 0;

    var stack = new Stack<(IElement element, int depth)>();
    stack.Push((root, 1));
    int maxDepth = 0;

    while (stack.Count > 0)
    {
        var (element, depth) = stack.Pop();
        if (depth > maxDepth) maxDepth = depth;
        foreach (var child in element.Children)
            stack.Push((child, depth + 1));
    }
    return maxDepth;
}
```
