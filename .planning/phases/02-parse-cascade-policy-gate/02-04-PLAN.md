## Critical Design Points

1. **AngleSharpStyledDocument implements BOTH IStyledDocument AND IPdfDocumentContext**: This is intentional. `DefaultStrictPolicy` receives `IPdfDocumentContext` from the caller, then casts internally to `AngleSharpStyledDocument` to access the AngleSharp DOM for CSS inspection.

2. **Eager construction**: Compute all four `IPdfDocumentContext` properties in the `AngleSharpStyledDocument` constructor. All four are needed by `DefaultStrictPolicy` regardless, so lazy evaluation adds complexity without benefit.

3. **TotalStylesheetBytes computation**: Walk `document.StyleSheets.OfType<ICssStyleSheet>()` and sum the byte length of each sheet's `CssText` property (or `OwnerNode?.TextContent` for inline `<style>` sheets). If the AngleSharp.Css API for CssText differs, use `sheet.ToString()` as a fallback — verify on build.

4. **Internal cast visibility**: `AngleSharpStyledDocument` is `internal sealed`. `AngleSharpCascadeEngine` constructs it. `DefaultStrictPolicy` reads it. Both are in `Muonroi.Pdf.Governance` — the internal cast is safe.
