| Boundary | Description |
|----------|-------------|
| host DI → IFeatureGate resolution | Whichever IFeatureGate is registered decides enforcement; a no-op binding silently disables licensing |
| license file/online → ActivationProof → LicenseState | Untrusted, attacker-controllable proof JSON crosses into the entitlement decision |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Elevation of privilege | DI binding of `IFeatureGate` | mitigate | `AddPdfEnterprise` uses `TryAddSingleton<IFeatureGate, LicenseFeatureGate>`; `AlwaysAllowFeatureGate` is never registered in the extension. Test 3 asserts the resolved gate type is `LicenseFeatureGate`. |
| T-16-02 | Tampering | ActivationProof RSA signature | mitigate | Gate delegates to `ILicenseGuard.HasFeature`, which reads `LicenseState` populated only after `LicenseVerifier` validates the RSA signature; a tampered proof yields `IsValid=false` → `HasFeature=false`. No new crypto (Don't Hand-Roll). |

| T-16-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan; nothing to verify. |
