# Muonroi.RuleEngine.Runtime.Web

[![NuGet](https://img.shields.io/nuget/v/Muonroi.RuleEngine.Runtime.Web.svg)](https://www.nuget.org/packages/Muonroi.RuleEngine.Runtime.Web/)

> Web APIs and real-time hubs for managing, deploying, and testing rules dynamically in the Muonroi ecosystem.

## Installation

```bash
dotnet add package Muonroi.RuleEngine.Runtime.Web
```

## Overview
Exposes REST endpoints and SignalR hubs for managing rule sets at runtime. It includes `RuntimeRuleSetController` for full CRUD, approvals, and canary rollouts. Real-time updates to connected clients or distributed caches are provided via `RuleSetChangeHub`. Safe testing is enabled by `RuleDryRunService`.

## Features
- **Rule Set API**: `RuntimeRuleSetController` supports rule management operations (`GET/POST/PUT/DELETE /api/v1/rule-sets`, `/approve`, `/canary`).
- **Flow Contracts**: Expose rule graph metadata using `MRuleFlowContractController` and `IMRuleFlowContractProvider`.
- **Real-Time Hot-Reload**: Broadcast rule changes across instances using `RuleSetChangeHub` (SignalR).
- **Dry-Run Testing**: Test rules without saving or impacting production state using `RuleDryRunService`.

## Quick Start
```csharp
// Register runtime web endpoints and SignalR hub
builder.Services.AddRuleEngineRuntimeWeb();

// In the application configuration pipeline
app.MapRuleEngineRuntimeEndpoints();
app.MapHub<RuleSetChangeHub>("/hubs/rule-set-change");
```

## Ecosystem Combinations

### + RuleEngine.Runtime → Remote Management & Scaling
Combine with the core runtime to build a centrally managed rule system where changes made via the API immediately propagate to all connected application nodes.

### + Experience Engine → Autonomous Rule Optimization
Dry-run rule variations generated by the AI using `RuleDryRunService`, and deploy successful configurations via the canary endpoints.
