# Muonroi.RuleEngine.Proliferation

[![NuGet](https://img.shields.io/nuget/v/Muonroi.RuleEngine.Proliferation.svg)](https://www.nuget.org/packages/Muonroi.RuleEngine.Proliferation/)

> Autonomous rule analysis, synthetic scenario generation, and AI proliferation models for the Muonroi ecosystem.

## Installation

```bash
dotnet add package Muonroi.RuleEngine.Proliferation
```

## Overview
Provides the "Brain" layer for the rule engine. Using implementations like `ClaudeProliferationBrain`, `OpenAiProliferationBrain`, or `OllamaProliferationBrain` via the `CompositeProliferationBrain`, it analyzes existing rules to autonomously build missing edge cases using `SyntheticScenarioGenerator` and `ChaosScenarioGenerator`. It converts text to logic with `NaturalLanguageRuleConverter` and executes these simulated paths via `ScenarioExecutor`.

## Features
- **AI Brains**: Leverage LLMs for rule generation using `ClaudeProliferationBrain`, `OpenAiProliferationBrain`, and `OllamaProliferationBrain`.
- **Scenario Generation**: Create edge case test definitions using `SyntheticScenarioGenerator` and `ChaosScenarioGenerator`.
- **Natural Language Parsing**: Convert human-readable logic directly into compiled rules with `NaturalLanguageRuleConverter`.
- **Dependency Analytics**: Trace nested graphs automatically via `CrossRuleDependencyAnalyzer`.
- **Scenario Execution**: Test AI-generated paths via `ScenarioExecutor`.

## Quick Start
```csharp
// Add the composite brain and scenario generation
builder.Services.AddProliferationBrain(options =>
{
    options.UseClaudeBrain(apiKey);
    options.AddChaosScenarioGenerator();
});

// Generate and execute scenarios
var brain = provider.GetRequiredService<CompositeProliferationBrain>();
var scenarios = await brain.GenerateSyntheticScenariosAsync(ruleSetId);
```

## Ecosystem Combinations

### + RuleEngine.Testing → Continuous Self-Testing
Scenarios generated by `SyntheticScenarioGenerator` can be passed to the testing layer to ensure that AI-written rules don't break existing requirements. 

### + RuleEngine.Runtime → Autonomous Edge Case Patching
If `CrossRuleDependencyAnalyzer` identifies a logic gap in a hot-reloaded rule, the Brain can propose a rule patch using `NaturalLanguageRuleConverter` and deploy it to a canary tenant.
