# Muonroi.Pdf.DesignSystem.Default

## Description
Provides the default design system and styling templates for Muonroi PDF documents.

## Features
- Pre-configured typography and layout defaults.
- Standardized color palettes and spacing.
- Easy to override for custom branding.

## Minimal Usage
```csharp
services.AddMuonroiPdf(builder => 
{
    builder.UseDefaultDesignSystem();
});
```
