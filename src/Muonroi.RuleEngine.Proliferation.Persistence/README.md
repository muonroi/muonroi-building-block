# Muonroi.RuleEngine.Proliferation.Persistence

[![NuGet](https://img.shields.io/nuget/v/Muonroi.RuleEngine.Proliferation.Persistence.svg)](https://www.nuget.org/packages/Muonroi.RuleEngine.Proliferation.Persistence/)

> Database storage for AI-generated scenarios, rule lineage, and proliferation telemetry in the Muonroi ecosystem.

## Installation

```bash
dotnet add package Muonroi.RuleEngine.Proliferation.Persistence
```

## Overview
Stores the outputs and historical trajectories generated by the Proliferation models. It leverages Entity Framework Core via `ProliferationDbContext` and `PostgresProliferationStore` to manage entities such as `NeuronScenarioEntity`, `RuleLineageEntity`, and `ScenarioResultEntity`. 

## Features
- **Proliferation DB Context**: Dedicated schema management using `ProliferationDbContext`.
- **Data Stores**: Efficient queries against AI outputs using `PostgresProliferationStore`.
- **Scenario Persistence**: Save and retrieve AI-generated scenarios securely through `NeuronScenarioEntity` and `ScenarioResultEntity`.
- **Lineage Tracking**: Track which AI model and prompt generated a rule using `RuleLineageEntity`.

## Quick Start
```csharp
// Configure Proliferation persistence
builder.Services.AddProliferationPersistence(options =>
{
    options.UsePostgresProliferationStore(connectionString);
});
```

## Ecosystem Combinations

### + RuleEngine.Proliferation → Stateful AI Brains
Connect the `CompositeProliferationBrain` directly to `PostgresProliferationStore` to track AI decisions, avoiding duplicate generation of scenarios by querying `NeuronScenarioEntity` history.

### + Experience Engine → Long-Term Memory
`ScenarioResultEntity` data feeds back into the Experience Engine to continuously measure the long-term success of AI-generated rules against real-world production metrics.
