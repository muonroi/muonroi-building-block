# Muonroi.RuleEngine.DecisionTable.Web

## Description
Web API controllers and UI components for managing and exposing Muonroi Decision Tables over HTTP.

## Features
- RESTful endpoints for evaluating decision tables.
- Management APIs for updating rules dynamically.
- Integration with Swagger/OpenAPI.

## Minimal Usage
```csharp
services.AddControllers()
        .AddMuonroiDecisionTableWeb();
```
