Architecture Decisions Summary

ADR-001 PdfSharpCore: Selected over iTextSharp 8 (AGPL incompatible with commercial distribution per legal memo LR-2023-041) and PDFium.NET (native C++ binaries per platform incompatible with Alpine musl containers). PdfSharpCore 89 of 100 score: MIT license, zero native dependencies, PDF 1.7 conformant, .NET 8 and netstandard2.0, IMPdfWriter abstraction for future swapping. Race condition on process-global FontResolver and FontFactory.Sources singletons mitigated via PdfRenderCollection DisableParallelization equals true. ADR-002 Byte-Equality Snapshots: Verify.Xunit rejected (manual approval blocks CI automation). Hand-rolled byte comparison against 56 committed embedded PDF baselines. MUONROI_UPDATE_SNAPSHOTS equals 1 regeneration protocol with mandatory visual review of all 56 PDFs. ADR-003 Informational Perf Gate: Hard 300ms CI gate rejected (72% false failures on GitHub Actions runners that show 380 to 1850ms cold render times). Stopwatch PERF-01/02 with generous ceilings 1500/400ms, tight goals 300/80ms in comment, Category equals SlowIntegration excluded from pre-publish gate, MUONROI_SKIP_PERF equals 1 escape hatch. ADR-004 CSS Allow-List: Explicit v0.1 allow-list over deny-list (incomplete, cannot defend against SSRF via @import). Covers display variants, margin/padding/border px, font px, colors, width/height, text properties, overflow, counter(). Flex/grid/float/position/transform stripped. ADR-005 EmbeddedResource Font: Noto Sans TestFont.ttf as EmbeddedResource. EmbeddedTestFontResolver returns embedded bytes for all IFontResolver.Resolve calls. SIL OFL 1.1. ADR-006 AddPdf DI: IMPdfService Scoped, ICssGovernance Singleton, IHtmlParser Transient, IFontResolver Singleton, ITelemetryService Singleton. ADR-007 Deterministic PDF: Fixed epoch CreationDate, SHA256-seeded trailer IDs, version-pinned PdfSharpCore.

Technical Pipeline Summary

Five-stage pipeline: (1) Validation+Parsing via AngleSharp 1.3.0 HTML5, limits MaxHtmlBytes 8MB/MaxElementCount 100k/MaxDomDepth 256, PdfInputLimitException on limit breach, billion-laughs protection via IEntityService. (2) CSS Cascade and Governance via AngleSharp.Css 1.0.0-beta.147, DefaultStrictPolicy.CheckCssFeatures calls GetComputedStyle per element O(n), checks forbidden display/float/position/border-collapse/import/scripts. (3) HTML Sanitization: strip disallowed CSS, remove scripts, neutralize external refs. (4) Rendering via HtmlRendererCore.PdfSharp 1.5.0.6: box tree, BFC, inline flow layout with text shaping, table layout, page breaks, font resolution via IFontResolver (production: mounted volume or S3; tests: EmbeddedTestFontResolver). (5) PDF Generation via PdfSharpCore 1.3.65: PDF 1.7 binary, font subsetting, XRef table, deterministic trailer IDs. PdfMeta returned with PageCount/RenderMs/EngineVersion/HtmlByteSize. Memory profile 50KB template .NET 8 Server GC: ~12MB DOM + 8MB CSSOM + 6MB layout + 2MB PdfSharp + 3MB output = ~31MB peak fully collectible. Container: mcr.microsoft.com/dotnet/runtime:8.0-alpine ~110MB, 512MB per worker, 1 vCPU per worker ~5-10 renders/second at 50KB. Pre-warm with no-op render at startup.
